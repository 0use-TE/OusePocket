# Core 0.39.1：右向横屏与应用排查

横屏改为与 0.39.0 相反的方向：逻辑旋转 270°，ST7796 在 swap XY 后使用反向的两轴镜像组合；竖屏映射不变。调试触摸反算和 LVGL 输入旋转同时更新，三键、手势、输入法沿用逻辑坐标。横竖屏之间是 90° 旋转；新旧两种横屏方向彼此相差 180°。

这项变更需要烧录固件。应用布局调整只需更新 BPK。Native API 仍为 41，没有新增游戏引擎接口。

## 应用调整

- 华容道、扫雷、井字棋、打地鼠：按实际视口布局棋盘；保持方格比例，横屏侧栏，竖屏上下排列。共享源码 `tools/app-shared/responsive-board.js` 嵌入各包，不依赖外部 JS 文件。
- 骰子、猜拳、反应测试、猜数字：横屏按内容与操作分区，竖屏上下排列；共享布局源码嵌入包中。24 点横屏同时显示数字牌和运算操作。
- 音乐、演示笔：移除越过横屏内容高度的初始绝对坐标，再按当前方向布局；防止冷启动在页面解析阶段失败。
- 普通纵向页面：内容不足以容纳时允许滚动。编码键盘、鼠标触摸板、骰子、猜数字、反应测试、猜拳及网络日志区保留可用高度，避免 fill 区域被挤成不可用的窄条。
- 商店、相册、文件管理等保留自己的列表滚动；外层纵向页面也可滚动，不删除原有操作。
- 计数器去掉 content 高度容器上的 flexGrow，避免容器被压缩后，其内部按钮被裁切且外层无法滚动到达。

仓库 37 个 BPK 均需通过打包、脚本语法及真机横竖屏冷启动检查；进度与发现的问题保留在本次诊断记录中。完成这些检查也不等于配对后的蓝牙控制、网络服务、摄像录音等全部外部功能均已重新验收。

## 版本变更日志

当前云端只有应用介绍、版本、作者、发布日期等字段，没有独立的 changelog/releaseNotes。应用介绍用于长期说明用途，建议后续新增独立版本说明，首次发布可选、后续更新建议填写。本次变更先记录在本文与版本发布清单中，没有用变更日志覆盖应用介绍。
