# 0.4.13 共享中文字库

本版使用仓库已有 OFL-1.1 字体生成静态 LVGL 位图，解决应用名称和 Wi-Fi SSID 中部分常用汉字缺字的问题。固件不携带 TTF 解析器，不依赖 Windows 字体，也没有下载新字体。

## 字符覆盖

源文件：`assets/fonts/NotoSansSC-Regular.subset.ttf`，1,618,528 字节。

SHA-256：`0f8774d017db6788a6375d8ad08eb639df6e074f330e740f77fc33acbd01992e`。

生成器使用 Python 标准库解析 TTF Unicode cmap（支持 format 4/12），源文件实际包含 format 4。统计结果：

| 项目 | 字符数 |
| --- | ---: |
| 源字体全部 Unicode 映射 | 5,512 |
| 其中 U+3400..U+9FFF 汉字 | 5,262 |
| 生成共享 fallback 的非 ASCII 可见字符 | 5,416 |
| GB2312 全部字符 | 7,445 |
| 源字库已覆盖的 GB2312 字符 | 5,321 |
| 源字库仍缺少的 GB2312 字符 | 2,124 |

截图中的“酷爱智能科技”“致远的个人热点”包含的汉字均存在，其中“酷”为 U+9177，“爱”为 U+7231。本次新增的账号、关于设备、设备与硬件、处理器、运行内存、机身存储、屏幕、触摸、麦克风、扬声器、无线连接、摄像头、电源管理、系统版本、设备名称、未知、本地账号文案，以及板级硬件描述中的 `·`、`×`、`²` 均已检查源字形覆盖。

这不是完整 GB2312 或完整 Unicode 字库。源字体没有的字仍可能显示缺字占位；现有 LVGL Source Han 14px 字库继续保留为最后一级 fallback，但也不保证覆盖所有生僻字或 emoji。

## 尺寸与 Flash

原有 20 档 UI 字体继续只包含固件、默认应用及翻译文案实际用字，使用 4bpp。新增三个共享 2bpp fallback，不给 20 档字号各扩展整套字库。

| fallback 像素字号 | 字形数 | 位图字节 | 字形/映射表字节 | 合计字节 | ascent/descent |
| --- | ---: | ---: | ---: | ---: | --- |
| 14px | 5,416 | 259,075 | 54,168 | 313,243 | 15 / 4 |
| 16px | 5,416 | 327,090 | 54,168 | 381,258 | 17 / 5 |
| 20px | 5,416 | 516,237 | 54,168 | 570,405 | 20 / 6 |
| 合计 | | 1,102,402 | 162,504 | 1,264,906 | |

总计约 1.21 MiB，另外仅需少量字体描述符及对齐空间。以上表大小按当前 `LV_FONT_FMT_TXT_LARGE=0` 的 8 字节 glyph descriptor 计算，最终 Flash 增量以固件构建报告为准。生成器对共享位图/映射表总量设 1,500,000 字节上限。

fallback 路径：主 UI 字体 ≤14px → 共享 14px；16/18px → 共享 16px；≥20px → 共享 20px；随后保留原有 LVGL Source Han 14px fallback（启用时）。应用名称与 SSID 使用该共享字体链。已收录的固件文案仍由对应主字号绘制，动态文案中未被主字库收录的字符使用上述共享字号，因此大号动态文字的生僻字未必与主字号同大。

主字体的行高和基线同时考虑实际字形及被选 fallback 的最大 ascent/descent，避免下沿或上沿被裁。14/16/20px 默认行高/基线分别为 19/4、22/5、28/6；小于 14px 的主字体为容纳动态中文字，行高至少为 19px。

字形位图常驻 Flash，使用 LVGL 现有的 2bpp 解码绘制路径，没有新增长驻 TTF/字体引擎内存。

## 生成方式与当前进度

`tools/generate-core-font.py` 只需要 Pillow 和 Python 标准库，已经移除 fontTools 依赖。`--coverage` 仅打印覆盖和容量统计，不写生成文件；不加参数则重新生成原 20 档字体、三个共享 CJK 字体及 UI 翻译头。

源文案扫描包含 core 原生 UI、runtime、板级硬件描述、默认应用清单与页面/脚本、`ui_strings.json`。

2026-10-16 已使用 bundled Python/Pillow 完成正式生成，本版实际 UI 子集为 341 个字符，缺字检查为零。更新了原 20 档字体、`ui_strings.h`、`ui_font_pool.h`，新增三个共享 CJK 字体文件。三个共享字体的实际位图/映射表尺寸与上表一致，总计 1,264,906 字节。

原 20 档主字体的位图合计 3,697,949 字节；最大 84px 主字体位图为 915,266 字节，未超过当前 LVGL 小字形描述符的单字库 1 MiB 上限。三个新增 CJK 文件在源码中的文本大小分别为 1,900,154、2,257,622、3,251,287 字节，这是十六进制 C 数组的源码大小，不是烧录体积。

已静态检查 14/16/20px 行高/基线为 19/4、22/5、28/6，主字体只指向对应共享 CJK，CJK 再指向已有 Source Han 字体，没有循环 fallback。生成器及生成文件的空白检查通过。未运行原生或真机测试，固件编译由主任务统一执行。
