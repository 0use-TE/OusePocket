# 0.4.13：独立 BPK 与原生设置

本版让应用自己的名称、图标和内部翻译随包交付，固件默认只保留设置。系统硬件服务、桌面、手势和设置继续采用原生 C/C++/LVGL。编译后用户进一步授权烧录、截图并检查系统：应用烧录、启动和最终原生系统操作检查均通过，14 张界面截图已目视检查。四个 BPK 已生成但均未安装，COM10 已释放。

## 应用和 BPK

- 资源监视和接口测试由固件内置应用改为独立 BPK，可以单独安装和卸载。
- 固件计数器源已删除，计数器示例保留在 `examples/usb-counter`，另提供 `examples/calculator`。
- 当前只有一种 BPK，ZIP_STORED 容器必须恰好含 `manifest.json`、`page.json`、`app.js`、`icon.bin`。清单没有包格式版本字段，脚本 API 保持 1。
- 默认 `name` 必填，`names.zh_CN/en` 可选；缺当前语言时回退 `name`。桌面和最近应用通过原生元数据即时更名，不运行应用 JS，也不借系统词表猜翻译。
- 包内 BGRA8888 图标按统一 dp 尺寸等比绘制，保留透明度，不叠加预设字体符号。PNG 在电脑上转换，板上不引入 PNG 图标解码器。
- 应用内部使用 JSON `translations/textKey`、JS `Ouse.locale.t/onChange` 自行维护文案，修正显式中英文绑定在切换中文时误走固件词表的问题。本版没有添加 XML 页面支持。
- 更新/卸载先在 UI 锁内清理旧实例、桌面/最近应用图标与图像缓存，随后工作任务才释放包，避免借用描述符悬空。

安装路径为 LittleFS `/ouse-apps`，仅管理该目录，保留其他已有文件，不自动迁移或清理。非空挂载失败不自动格式化。所有包、工具和扩展采用同一契约，详见 [BPK 说明](bpk.md)。

## 设置与 Wi-Fi

设置首项为账号卡：原生头像、Ouse 名称与本地账号页，仅展示本地账号，不接云端。底部“关于设备”使用 Android 风格规格列表，显示设备名称、核心版本和板级描述。

硬件描述由 `boards/waveshare_lcd35/ouse_board.c` 提供：ESP32-P4/400 MHz、32 MB PSRAM、16 MB Flash/microSD、3.5 英寸 320×480 ST7796、FT6336 触摸、ES8311 音频、8 Ω/2 W 扬声器、OV5647/500 万像素 MIPI-CSI 摄像头、ESP32-C6 和 AXP2101。型号依据当时归档的微雪产品说明（旧目录现已移除，当前板级声明见 `boards/waveshare_lcd35/ouse_board.c`）的硬件概览，属于板级静态规格，不是运行时探测到的外设清单。规格中的 BLE 是硬件能力，本版没有开放蓝牙服务。关于设备不再显示堆使用量，实时资源查询由资源监视 BPK 提供。

Wi-Fi 页采用当前网络、可用网络分组，包含信号/加密标记、刷新、网络详情、手动添加、连接/断开与忘记操作。开放网络直接连接，加密网络才输入密码。仍使用现有 Wi-Fi Remote → Hosted → SDIO/C6 工作任务，没有更换无线依赖或关闭 Wi-Fi。

新增共享 14/16/20px、2bpp 中文字体，包含截图 SSID 的“酷爱”等字，原 UI 20 档字体仍按实际文案裁剪。共享源覆盖 5,262 个汉字，不声称完整 Unicode/GB2312。位图/映射表共 1,264,906 字节，生成器仅需标准库/Pillow；详见 [字体记录](0.4.13-fonts.md)。

## 后续边界

本版暂不开发音乐、倒计时和闹钟后台 API，不添加 XML 解析器。后台页面仍暂停 JS，系统硬件工作任务独立运行；“硬件服务在后台”不等于每个应用脚本持续执行。

资源监视当前显示堆、CPU 配置频率、物理 Flash 容量及运行时间，尚没有 CPU 占用率或应用存储统计。自定义启动器图标已支持，其他页面资源、音频文件、多资源目录与应用私有数据仍待完善。账号云端能力等待后续需求；摄像头规格已根据产品说明登记，但摄像头运行功能不属于本轮实现。

本次已授权的原生系统检查完成并停止，四个 BPK 未安装。冷启动、长时稳定性、BPK 安装/图标/语言切换、声学效果和摄像头运行尚未验收。完整交接和历史证据见 [当前状态](STATUS.md)。
