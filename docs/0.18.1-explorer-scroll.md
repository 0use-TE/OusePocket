# 0.18.1 连续滚动资源管理器

界面去掉路径、本页数量、只读说明、常驻容量、页码和翻页按钮。顶部仅显示当前文件夹名，保留返回、刷新、信息。容量移入“信息”弹窗；文件夹和文件使用不同图标，名称不再带文字类型前缀。无卡提示和文件详情保留。

目录现在上下连续滚动，接近底部自动加载更多；向上滚动可重新读取前面的条目。底层仍每次枚举八项，但用户不再操作分页。视图保持最多 24 行，滚动窗口按八项回收，避免超过 JS 128 节点预算或为超大目录长期保留全部文件信息。刷新与进入新文件夹会回到顶部；末尾不足八项时保持窗口索引对齐，避免向上滚动重复/漏项。

内核新增 `Ouse.ui.getScroll(id)`，返回缓存的 `{y,bottom,height,pending}`；`Ouse.ui.scrollTo(id,y)` 提交异步定位。坐标遵循页面 dp/px 单位，JS 不直接访问 LVGL；布局更新后才应用定位、发布滚动状态。Core 0.18.1 / C API 20 / JS API 1。

离线验证：`node tools/test-explorer.cjs` 覆盖连续续载、24 行窗口双向回收、不满批次的末页、返回上层、无卡、错误和简洁显示；当前资源管理器与音乐包均重新通过原生包解析、QuickJS 编译和生产控件 schema 验证。音乐脚本生命周期回归也通过。
