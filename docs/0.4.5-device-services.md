# 0.4.3～0.4.5：电源、音频与 C6 Wi-Fi

本轮合并发布为 **0.4.5**，公共核心 API 4、应用运行时 API 1 保持兼容。编译、主机交互与驱动故障模拟已验证；电池、音频电气链路和 C6 实际协议兼容性仍需烧录验收。

## 设置行为

设置和下拉面板不显示保存按钮、保存成功页脚或重启说明。亮度立即预览、松手自动入队；主题、语言、字号立即更新。音量、静音、熄屏时间和无线偏好由独立后台任务自动保存，连续变更在安静 300ms 后合并写入。

成功不打断用户；失败弹对话框，可重试。忘记网络先确认。数据/能力状态（电池电量、连接中、录音时长）属于实际功能内容，继续显示。

## 结构与线程

`components/ouse_devices` 保存公开状态快照、配置和三个版本序号。UI/JS 请求只做参数检查、复制和通知；板级任务读取最新命令，旧请求完成不会覆盖新请求。临界区内不进行 I/O。

`boards/waveshare_lcd35` 提供三个后台任务，全部使用内部 RAM 栈：

| 任务 | 职责 | 行为 |
| --- | --- | --- |
| ouse_power | PMIC、设备配置持久化 | 每 2 秒读取 PMIC；合并设置后写 NVS |
| ouse_audio | 唯一 I2S/ES8311 所有者 | 空闲等通知；按需初始化、录放、停止 |
| ouse_wifi | Hosted/Wi-Fi 请求和 SDK 事件 | 默认关闭；启用后初始化，连接期间处理事件/超时 |

SDK 网络事件回调只复制事件、唤醒无线任务；不调用 JS 或 LVGL。LVGL 的应用定时器按变化序号投递通知；后台合并、恢复补发、关闭释放订阅。

`available` 表示板级功能/任务可用；音频芯片按需检测，操作失败通过 error 返回。Wi-Fi 的 ready 表示已完成传输握手和 SDK 初始化；电源 valid 表示最近 PMIC 读取成功。

## 电源

使用 BSP 已建立的 I2C 总线，在 0x34 探测 AXP2101。读取状态寄存器 0x00/0x01、SOC 0xA4、电池电压 0x34/0x35。充电方向用状态 1 的高位字段判定，不把所有非满电状态都视为正在充电。

不改 PMIC 电源轨、ADC 开关或充电参数；没有有效电压时显示未知。没有电池与 PMIC 读取失败分别处理。状态栏实际显示电量/充电，未知时保留占位。

自动熄屏支持 0、15、30、60、120、300 秒；默认 60 秒。仅关闭背光，MCU、无线及应用继续运行，不提供深睡眠或 PMIC 硬关机。录放音测试和对话框打开期间不自动熄屏。

`ouse_screen.c` 包装原 BSP 输入读取回调，保留输入设备的模式和上下文。熄屏后第一份按下数据先恢复背光，并将这次接触直到松手的所有数据转为释放状态，因此不会点到应用或触发导航。亮度在熄屏期间修改时只更新目标值，唤醒使用最新值。

## 音频

按照 BSP 引脚和 esp_codec_dev，建立唯一的 ES8311 BOTH 模式及 duplex I2S：MCLK13、SCLK12、LRCK10、DOUT9、DIN11、PA53。与显示、触摸和 PMIC 共用已建立的 I2C 总线，不重复安装总线。

支持音量 0～100、静音、0.5 秒 440Hz 渐入渐出测试音、1～3 秒录音、录音回放和停止。数据格式固定 16kHz/16bit/单声道；短录音最多 96KiB PSRAM，只保留一份，不写文件或 Flash。

录音时输出静音，避免直接监听啸叫；峰值来自实际 PCM。停止请求改变版本序号，录放循环逐帧检查。I2S I/O 使用组件的 1 秒超时；结束/取消关闭 codec，失败释放已创建的接口和 I2S 通道，允许下次操作重新初始化。设置和接口测试离开时停止其录放测试。

本版未接入 MP3 解码、文件音乐库或持续后台播放器。

## Wi-Fi

依赖沿用已归档版本，并固定到锁文件：Hosted 2.12.3、esp_wifi_remote 1.6.5、wifi_remote_over_eppp 0.3.3、eppp_link 1.1.6、esp_serial_slave_link 1.1.2。实际传输使用 SDK 6.1 内置 Wi-Fi Remote 与 Hosted SDIO，EPPP 不启用。

SDIO slot 1、4 位、25MHz：CLK18、CMD19、D0～D3 为 14～17，C6 Reset54。蓝牙关闭，Hosted 通信失败重启主机/传输的选项关闭，Hosted 默认任务栈保留在内部 RAM。

构建时用产品 CMake 覆盖 Hosted 自动 constructor/destructor 的单个源文件，保留其目标、依赖和 whole-archive 属性；校验上游源文件指纹，不修改 managed_components。产品在桌面 READY 后建立无线任务，开关默认关闭时不调用 Hosted 初始化；保存为开启后，下次启动才在后台恢复。C6 握手失败不会阻塞桌面，仍需实机检查上游驱动行为。

支持：

- 非阻塞扫描，最多 12 个结果，按 SSID 去重。
- 原生密码键盘，手动输入其他/隐藏网络；SSID 原样显示，不参与系统翻译。
- 开放网络或 WPA2/WPA3 个人网络；SSID 1～32 UTF-8 字节，密码为空、8～63 字节或 64 个十六进制字符。
- IP、RSSI、断开、忘记、自动恢复保存的连接；只有成功取得 IP 才保存新密码。
- 非主动断线最多重试两次；认证失败直接报告，扫描/连接 15 秒后退出；修正密码或重新操作可再试。
- C6 初始化失败或链路失效保留错误状态，手动操作可重试；不会自动无限启动新的驱动任务。
- 连接成功启动 SNTP，默认 UTC+8；未校时仍显示未知时间。

无线任务在空闲/关闭时等待通知，不定时唤醒；连接/扫描期间才用短超时检查，已连接时约 5 秒更新 RSSI。关闭开关停止 STA，但保留已初始化的上游 Hosted 传输基础任务，避免反复拆装驱动。

初次启用会记录从机 Hosted 版本。主机固定 2.12.3，实际从机是否兼容以板上握手和扫描/连接为准；本包不改写 C6 固件。动态 SSID 使用常见 CJK 回退字体，仍不是全 Unicode 字库。

Wi-Fi 密码不出现在公开快照、脚本 get() 或日志里。原生设置的“忘记网络”清除保存的 SSID 和密码。

## 板上验收

1. 正常进入桌面，默认 Wi-Fi 关闭；设置和面板没有保存按钮/成功页脚。
2. 设置 15 秒熄屏，等待背光关闭；点在应用按钮上唤醒，应只亮屏，第二次点按才操作。改亮度后验证恢复值。
3. 插/拔外部供电、连接电池时检查电量/充电状态，未知信息不能伪装为有效值。
4. 播放测试音，调整音量/静音；录音 3 秒看麦克风电平，回放、停止，反复进入退出声音页。
5. 打开 Wi-Fi，查看 C6 版本、扫描结果；错误密码应能退出并重试，正确密码取得 IP，连接后等待时钟校准。
6. 检查断开、关闭、忘记、隐藏网络和网络丢失后的有限重连；不能冻结桌面或反复重启主机。
7. 修改主题、语言、字号、亮度、音量、静音、熄屏时间、Wi-Fi，等待约 1 秒正常重启检查恢复。不要重刷完整合并镜像来验证保存，因为它会重置 NVS。
8. 接口测试显示实际快照并能操作；后台恢复通知有效。记录异常时保留完整串口日志及匹配的 `tmp/symbols/0.4.5/` ELF/MAP。
