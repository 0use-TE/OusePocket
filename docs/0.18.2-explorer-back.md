# 0.18.2 资源管理器返回

侧边返回和三键导航的返回键采用同一优先级：先关闭文件详情/存储信息弹窗，然后返回上一级文件夹；只有在 SD 根目录时才交给系统返回桌面。加载目录期间消费返回事件，不会误退出；桌面上滑手势不受影响。

新增 `Ouse.navigation.onBack(fn|null)` 注册应用返回回调，`setBackEnabled(bool)` 提供同步缓存的拦截状态。系统 UI 线程仅消费事件并唤醒 JS 工作线程，不同步调用 JS；回调在应用工作预算内执行，事件带实例当前 generation，关闭/故障/暂停后不触发过期回调。未启用自定义处理的其他应用沿用原有页面栈行为。

资源管理器将当前目录非根目录或正在加载设置为拦截状态，顶部返回按钮和侧边返回共用同一上级目录函数。到达根目录后关闭拦截。

版本：Core 0.18.2 / C API 21 / JS API 1。`node tools/test-explorer.cjs` 覆盖详情弹窗优先、子目录回上级、加载期间不退出和根目录交回系统；当前四个交付应用通过原生 BPK/QuickJS/schema 检查。

2026-10-18 已更新应用区固件并替换资源管理器。实际触摸侧滑通过：关闭详情 → Music 回 Ouse → Ouse 回 SD 根目录 → 根目录回桌面；中间两级均保持资源管理器前台。刷新、重开与目录浏览回归通过，运行时错误为 0、堆检查 `ok=1`，COM5 已释放。无卡时不拦截返回，避免困在已经失效的子目录。
