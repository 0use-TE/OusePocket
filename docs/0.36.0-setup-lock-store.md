# 0.36.0 首次引导、设备名、锁屏密码和内置商店

首次启动进入原生引导：欢迎 → 必填设备名 → 可跳过 Wi-Fi → 可选六位数字密码 → 简单使用 → 桌面。名称与引导进度在独立 NVS blob 中保存，名称上限为 24 个 UTF-8 字节，不能为空、首尾空格或控制字符；支持合法 UTF-8。引导完成后正常重启不再重复。中途断电可从已提交阶段继续；已设置密码的未完成引导也必须先解锁。

界面按真机反馈精简：欢迎页只保留标题与开始按钮，名称页只有一句蓝牙提示，使用引导缩为三项操作。数字密码键盘固定在屏幕底部，取消放在数字 0 左侧。联网页自动开启 Wi-Fi 并扫描附近网络，主界面只有网络列表、刷新和跳过；没有 SSID 输入框。点击加密网络才显示独立密码页，键盘确认直接提交连接；开放网络直接连接。连接成功后“跳过”变为“下一步”。

设置新增“设备名称”和“密钥”。设备名与 BLE GAP Device Name、扫描响应中的完整名称共用同一持久化值。完整名称放在扫描响应里，避免 31 字节广播包同时放 HID 服务、外观和长名称时超限；已连接对端可能缓存旧名字。

密码只接受恰好六个 ASCII 数字，包括前导零；新密码必须确认两次，修改和关闭必须验证旧密码。原生数字键盘不使用通用输入法。重启、主动息屏和自动息屏都进入密码界面；唤醒触摸仍完整吞掉。应用打开、全局导航手势和应用侧键接管不能绕过界面。锁屏不退出正在运行的应用或停止原生后台服务。

密码不明文持久化：独立随机 16 字节盐，PBKDF2-HMAC-SHA256 / 10,000 次，保存 32 字节结果，比较时不按首个差异提前退出。连续错误五次限制 30 秒，错误计数持久化，重启不会清除限制。密码派生和 NVS 写入在独立原生任务执行，UI 只提交请求、读取缓存；保存成功后才应用新状态。任务注册到现有收尾机制。队列只传拥有者指针，临时明文缓冲用后擦除；配置界面和锁屏期间不记录触摸坐标。此功能是界面访问锁，不是应用数据加密或针对固件重刷的防护。

应用商店仍是可更新 BPK，构建时自动打包 `apps/store` 并嵌入主固件。存储挂载后，如果商店缺失或损坏，则从固件写入临时文件，flush/fsync 后原子替换；有效的现有商店不覆盖，保留后续更新及应用数据。商店属于系统应用，桌面不显示卸载叉号，管理页不能卸载，安装服务同样拒绝卸载请求。只烧录主固件也能在空白 LittleFS 上得到商店，无须另装 BPK 或预制文件系统镜像。
