# Button + LED V1

2026-10-19。嘉立创工程 `OusePocket / Board1`。第一块按键灯板采用 **UP1 通用背部扩展平台**：统一 PCB、排针、安装孔、相机避让和底座；后续模块只改变功能元件、走线及上盖开孔。旧的 22×52 窄条板与跨正面侧夹方案已取消。

平台尺寸定义见 [`universal-platform.json`](../mechanical/universal-platform.json)。本版用一个按键通过固件切换一个红色 LED，PCB 收在完整背壳内。

- `button-led-v1.epro2`：完整原理图与 PCB。
- `button-led-v1-gerber.zip`：制造输出，尚未下单。

- `universal-base.stl`：共用底座，后续模块保持不变。
- `universal-lid-blank.stl`：共用上盖毛坯，保留相机孔、四个螺孔，供新功能改孔使用。
- `button-led-lid.stl`、`button-cap.stl`：本版功能上盖及按钮帽。STL 单位 mm、底面已放在 Z=0；相应 STEP 保留装配坐标。上盖有悬空桥接，切片时应检查支撑和放置方向。
- `pcb-eda.png`、`schematic-eda.png`、`assembly-preview.png`、`assembly-open-preview.png`：PCB、原理图、合盖与开盖预览。
- `firmware/`：独立 ESP-IDF 最小样例，已编译、未刷写；尚未集成到 OusePocket 桌面系统。

## 电路与 BOM

| 位号 | 器件 | 连接 |
| --- | --- | --- |
| J1 | 普通 2×16、2.54 mm 直插公针，自建封装 `OusePocket_2x16_MATING_V3` | 底面安装；模型参考塑壳约 2.5 mm、插接端约 6 mm，实购件需核对 |
| SW1 | TS-1187A-B-A-B / C318884，5.1 × 5.1 × 1.5 mm | 1、3 接 BTN_N；2、4 接 GND |
| R2 | 10 kΩ / 0603 / C25804 | 3V3 → BTN_N 上拉 |
| R1 | 1 kΩ / 0603 / C21190 | LED_GPIO → LED_A 限流 |
| D1 | KT-0603R 红灯 / C2286 | A（2）接 LED_A，K（1）接 GND |

J1.13（GPIO34）接 BTN_N，按下为低；J1.24（GPIO33）接 LED_GPIO，高电平点亮。J1.2 为 3V3，J1.3/4/9/23/32 均接 GND。其余接口引脚标为不连接；未使用 5V、VBAT、LDO_V4、USB 或 C6 信号。

从主机背面原图旋转为当前竖屏视图后，排母在右侧，奇数脚为外侧一排。定制封装已按这一对插方向安排。引脚名称与 BTN_N、LED_GPIO 等网络名称独立。

## 装配参考与实物待确认项

主机外廓采用官方图：正面 Z=-14.1 mm，背壳表面 Z=-0.6 mm，脚垫最高面 Z=0。PCB 与主机中心重合，底面 Z=4.2 mm，排针中心 X=24 mm。公针最深端约 Z=-4.3 mm，名义插入量约 3.7 mm。外壳从 Z=0.6 延伸至 Z=10.6 mm，独立按钮帽最高 Z=12 mm。

底座用可移除贴片固定在背壳。PCB 从背部沿排针轴线对插，套入按钮帽和上盖，再用四颗螺钉固定到共用底座。没有向正面延伸的侧夹，也没有伸出机器侧面的窄条板。更换模块时保留底座，换相同板框的 PCB 和相应功能上盖。

相机孔为贯穿挖槽，而不是第二个板框；对实际 STEP 的 PCB 材料体进行探针求交，确认相机中心为空。较大的上盖相机孔用于减少厚壳遮挡，尚未做光学视场验证。

**尚未完成实物配合。** 排母料号、中心坐标和凹陷深度仍需测量；贴片附着、按钮帽活动间隙、打印孔和螺钉需要试件确认。主机按键、USB、卡槽未完整建模，接口避让仍需看实物。PCB 和主机均未因本方案打孔；CAD 无干涉不代表已经装机成功。UP1 是当前拟定平台接口，实测校正前不应冻结量产尺寸。

## 验证

- 最终 PCB：五个网络布线完成；严格 DRC 为空，见 `final-pcb-drc.json`。
- 原理图：电气错误为零；保留两个 `ATTRMATCHCODE` 库属性匹配提示（D1、SW1），见 `final-schematic-drc.json`。
- 通用底座、上盖毛坯、功能上盖、按钮帽均为有效单实体；所有外形都位于主机投影内。实际 PCB 与安装件的体积干涉结果见 `assembly-check.json`。
- STL 导出前检查闭合实体；原窄板、托架和侧夹打印文件已移除。
- 独立固件：ESP-IDF 6.1 / ESP32-P4 rev ≥3.1 编译通过，30 ms 消抖、按下沿切换 LED、长按不重复、初始熄灭。未刷写、未上板验证；不同芯片版本需调整配置。
