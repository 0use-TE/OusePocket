# 0.15.0 桌面与手势

核心 C API 16，BPK/JS API 仍为 1。

## 交互

- 320×480 目标屏幕的桌面统一为 3 列 × 4 行，每页 12 个应用。多页显示底部圆点，安装/更新尽量保留当前页，删除末页后夹紧到有效页。
- 字体图标以自身中心为缩放轴，修正最近应用标题栏的小图标向左上偏移。
- 底部上滑松手回桌面，上滑后停顿 120 ms 进入最近应用；正常手抖容差保持。最近应用中底部再上滑回桌面，卡片区域上滑仍关闭该应用。
- 手势横条随上滑抬升，最近应用中保持轻微抬升，退出或取消后平滑复位。
- 快速回桌面用实时应用层平移，取消手势开始时的截图、复制以及全屏图像缩放/透明合成。快滑完成后暂停应用；预览延后到需要时生成。最近卡片借用注册表持有的预览，先删除卡片再释放预览。
- 倒计时使用橙色沙漏，秒表使用青色秒表图标，均由确定性几何图形生成。
- 系统服务测试 BPK 改为分类首页和系统状态、网络、媒体、闹钟、USB 五个子页；保留 URL 草稿和跨页请求结果，只访问当前挂载页控件。

## 开发者选项

设置 → 开发者选项 → MCP 设备调试。界面仅保留开关，移除开关下方的小字说明。编译包含设备调试时可动态开关，不需要重启；异步保存到 NVS。默认延续旧版开启状态，关闭后可在设置中重新开启。

此开关控制设备侧串口 `DBG_*` 能力：截图、输入注入、控件树和诊断。电脑端 stdio MCP 进程仍由电脑管理。HELLO 按当前状态返回 debug=0/1；BPK 安装、列表、更新和卸载保持可用。

关停后拒绝新调试命令和尚未执行的 UI 调试回调，清除缓存回复，串口工作线程释放抓图资源和临时调试状态。正在执行的命令可能先完成；关停轮询周期 250 ms。保存失败由原设置错误通道报告，当前启动内的状态仍立即生效。未编译设备调试的固件显示禁用开关。

## 验证

本地构建、JS 分类导航/跨页异步结果/文本字节预算、应用包生产解析与页面 schema、设置保存及失败重试、PSRAM 分配器回归验证通过。设备 Unity 测试覆盖快滑回家、停顿进入最近应用、短滑取消、最近应用底部上滑退出和开发者调试拒绝逻辑。

2026-10-17 经 SSH 使用设备所在 Windows 电脑的 CH343 COM5 完成烧录，应用区地址 `0x10000`，哈希校验通过；保留 NVS 和 LittleFS。最终应用区 4,992,640 字节，SHA-256 `dcb7ff3f439eb932ad3c159359414bd4e37ec02ca8322c618f01d9bd6a74710f`。

真机结果：

- 原生 Unity 7 项检查全部通过，包括动态调试禁用后的命令拒绝及恢复。
- 系统服务、倒计时、秒表 BPK 更新通过；服务五个子页逐个进入并返回，运行时 errors=0。
- 临时添加 3 个分页测试包，共 13 个注册项：第一页 12 个，第二页可达；更新已有包后仍停在第二页；删除测试包后回到有效页，测试包已清理。
- 底部上滑停顿进入最近应用后 `bar_offset=-6`；再次从底部上滑返回桌面且保留实例。重复快滑回家 5 次及再次打开最近应用通过，堆完整性检查 ok。
- 截图复核中修正了应用层首次布局尚未完成时记录了错误回弹位置、以及新开发者开关未使用系统皮肤的问题。最终版本开发者页开关可见、开启且可操作，设备留在桌面，串口已释放。
- NVS 新旧数据兼容、关停保存、保存失败/重试由真实系统后端主机测试验证；本轮没有进行“物理关闭后跨重启、再手动开启”的完整真机人工验收。
