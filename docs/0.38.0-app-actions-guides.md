# 0.38.0 应用操作与引导

## 行为

- 应用管理详情底部改为一行：打开、清除数据、卸载。三项等宽，破坏性操作保留二次确认，系统应用的保护规则不变；标题显示当前应用名。
- 安装服务在发布 succeeded/failed/cancelled 终态前先刷新原生应用目录，保证读取安装完成后的 packages.list 已看到提交后的版本，消除真机复现的旧清单竞态。
- 商店当前已安装版本不低于目录版本时，主按钮为“打开”，不再显示“重新安装”。有新版时主按钮为“更新”，仍可打开已安装版本。安装终态、详情打开和恢复前台时更新清单与按钮；成功安装后主按钮立即改为打开，同时隐藏重复的次按钮。
- 网易云、鼠标、演示笔、开发者工具使用一致的引导：首次 ask 请求一次；denied 显示权限设置入口且不重复请求；蓝牙关闭、启动中、未连接设备、HID 输入服务未就绪、被其他实例占用分别显示状态与可操作入口。报告发送仍受原有原生权限、所有权、连接、加密、认证和通知订阅检查。断线取消本地按键/播放状态，暂停/关闭释放原生租约。
- 相机、录音机、相册的拒绝提示提供权限设置入口。相机拒绝后不以刷新计时器循环弹出提示；恢复前台后重新检查。相册按当前活动页面绑定按钮，避免向未加载的页面注册事件。
- `Ouse.system.openSettings("permissions"|"bluetooth"|"wifi")` 是 API 40。请求在脚本线程只保存有界目标，由 UI 线程处理；验证实例、非前台、关闭和故障实例不能提交。permissions 的应用 ID 来自调用实例，不接受第三方目标 ID；锁屏/引导期间禁止打开设置。进入自己的权限页或无线设置后可返回调用应用。不自动改权限、不清除拒绝、不自动开启蓝牙。
