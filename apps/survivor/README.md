# 荒野生存 2.0.0

使用与跳跳庄园共用的前台帧调度器、原生 Canvas 场景、透明触摸控件及系统游戏模式。需要 Native API 47（Core 0.44.x）。

- 1280×960 世界，双轴镜头跟随，全屏游玩，25 FPS 上限；物理按 60 Hz 固定步长计算。
- 四名角色：游侠翻滚、重装铁壁、工程师哨戒炮、疾风闪身。
- 六类主武器：突击步枪、散弹枪、冲锋枪、穿透狙击枪、范围榴弹炮、连锁电弧枪。枪械可强化至五级。
- 四种伙伴：护卫犬近战、磁力猫拾取、医疗蜂治疗、火尾狐火环。角色、枪械、伙伴、区域均可直接在整备营地选择；选择自动保存。
- 荒野草原、锈蚀工厂（毒池）、霜夜营地（冰面减速）。普通、疾行、重装、远程敌人，以及第四/第八波冲锋首领。
- 八波每波 25 秒，首领波必须击败首领。经验升级和波间三选一；可获得飞剑、爆破、恢复、护甲等强化。
- 固定池：24 敌人、32 主弹、18 经验物、12 敌弹、8 短特效。经验池满时合并数值；每张 Canvas 最多 256 条绘制命令。
- 动态营地菜单，无版本号、英文副标题和宣传小字。保留左右手摇杆、特效偏好、最高击杀及已有存储 ID。
- 原创程序像素素材和离线合成音频直接打包，播放和混音走原生服务。暂停/后台停播，关闭释放任务。

构建：python tools/build-survivor.py
行为测试：node tools/test-survivor.cjs
原生包校验：python tools/test-ouse-app-packages.py --apps survivor
产物：dist/apps/荒野生存.bpk

engine.js 是独立确定性战斗引擎，game.js 负责界面、输入和绘制；tools/app-shared/game-runtime.js 同时用于两个游戏。
自动战斗路线仅使用正常移动、技能和强化选择，不代表人工实机完整通关。

游戏内角落显示实测 FPS，每秒统计实际游戏更新/绘制回调；不是屏幕扫描刷新率。暂停或后台后重置统计，首次采样前显示 -- FPS。
