## 真机发现及修复

0.12.0 把 JSON fontSize 请求上限缩到 40，导致原设备计数器包中 72px 的节点未通过恢复校验，应用没有注册到桌面；包文件仍保留。0.12.1 恢复请求范围 8..84，统一映射实际 8..40 字体池，大于 40 使用 40px。系统倍率仍固定 100%，不恢复字号设置，不增加大字号字库。预览同步映射，相关主机检查及修正版构建通过。

四个原有包 api-test、calculator、counter、resources 均恢复并保留。api-test 更新为匹配本轮接口的包，其余原有包未覆盖。计数器和语言页实机截图已目视检查。原有深色、中文、100% 设置保留。
