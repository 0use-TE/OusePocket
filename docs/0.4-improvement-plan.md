# V0.4 改进方案与进度

这份文档整理 2026-10-16 的需求和代码核对结果。第一批 0.4.1 已由用户确认正常；第二批 0.4.2 已实施，主机测试通过，待板上验收；0.4.3～0.4.5 已作为 0.4.5 合并实施，待硬件验收。
基线是已经完成启动、显示、触摸和资源监视实机验证的 V0.4.0；长时间交互仍需逐批验收。
本轮先完善固件内置应用和系统体验，BPK、USB 安装单独安排。

## 分批顺序

| 建议版本 | 范围 | 主要验收结果 |
| --- | --- | --- |
| 0.4.1 | dp/sp、字体尺寸、布局基础、主题通知、中英文本地化、内置接口测试应用 | 换主题/语言/字号无需重启；应用状态保留；桌面名称不裁切 |
| 0.4.2 | 原生桌面、快捷面板、设置、侧边返回、Home/最近应用交互 | 下拉和返回跟手；上滑回桌面、上滑停留进最近；清除全部、点空白退出 |
| 0.4.3 | 电源状态、自动熄屏、触摸唤醒 | 电池/外部供电/充电状态可读；熄屏时间可配置，唤醒手势不误点应用 |
| 0.4.4 | 音频后端和界面/API | 音量、静音、内置试听播放/停止、麦克风电平与短录音回放可测试 |
| 0.4.5 | Wi-Fi Remote + C6 SDIO | 扫描、密码输入、连接/断开、IP/RSSI、重连和失败恢复可测试 |

接口测试应用从第一批加入，每批扩展；每批提供独立构建和验收记录，避免把所有硬件同时打开后再排查。
版本号为建议，实施时以最终范围为准。

## 实施前的问题与参考

- 当前快捷面板仅在触摸松开后判断位移并显示/隐藏，没有 Pressing 阶段跟随。
  归档 `shell_display.cpp` 和 `shell_quick_controls.cpp` 有拖动位置、输入屏蔽、取消旧动画、180ms 收尾逻辑。
- 当前桌面图标 tile 高 112px，名称从 y=96 开始，而 UI 字体行高为 22px，只剩 16px 的空间，存在明确裁切条件。
  图标符号本身为 24px，外层却预留 92px 高的区域，也会导致视觉松散。
- 当前底部上滑直接打开最近应用，需要替换成能区分上滑释放与上滑停留的交互。
- 归档有最近应用 close_all 和返回桌面逻辑，但用户要求隐藏顶部“最近应用”文字，最终行为以新需求为准。
- 归档 `pocket_platform.cpp`、`pocket_battery.cpp` 使用 I2C 0x34 的 AXP2101 读取电池信息；它没有实现充电配置控制。
- 归档 `waveshare_audio.cpp` 使用 BSP/esp_codec_dev 控制 ES8311，包含音量和本地播放实现。
  当前 BSP 也有 speaker/microphone 初始化入口；迁移时统一管理共享 I2S/codec 生命周期。
- 归档 Wi-Fi 使用 esp_hosted 2.12.3、esp_wifi_remote、C6、SDIO slot 1 四线、25MHz、reset GPIO54。
  Host/C6 固件兼容性需要实际握手确认，不能只复制 Kconfig。
- 归档语言设置保存偏好后显示重启确认；这属于原有产品实现策略，不是 LVGL 必须重启的限制。

## 已实施范围

0.4.1 提供 dp/sp、多字号字体、即时中英文、主题/语言/显示变化通知和 JSON＋JS 接口测试。
0.4.2 提供原生共享控件、彩色桌面图标、设置首页和四个子页、跟手快捷面板、边缘返回反馈、Home 预览收尾、停留进最近、居中吸附和卡片关闭动画。
最近应用有全部清除、空白退出；滑块和系统手势互斥。触摸候选手势期间启用短期 UI 定时器读取已采样坐标，空闲暂停，不增加硬件轮询服务。
电源、音频、C6 Wi-Fi 已实现；用户要求的自动保存和失败对话框同时落地。实现边界与验收步骤见 docs/0.4.5-device-services.md。

## 显示、主题和本地化基础

1. 统一逻辑单位：布局用 dp，文字用 sp；设备逻辑密度与用户字体倍率分开。
   当前板可以选定 1dp=1px 的默认逻辑密度，但这只是产品配置，不代表物理 DPI。
   所有坐标、圆角、间距、图标和手势阈值都走同一换算；字号另加字体倍率。
2. 除换算外增加行列布局、可用宽度、内容高度、换行和最小尺寸规则。
   状态栏/手势区域有统一安全边距。旧 JSON 数字保持原来的 px 语义，新页面显式声明单位，防止静默改变旧页面。
3. 首版采用共享的多字号字体池，覆盖中英文系统文案及所有内置应用文案，提供离散字号档位。
   字号变化选择合适的已生成字形，重新排版，不把整页当图片拉伸；字体数据不按应用重复拷贝。
   不在每帧动态生成字形，也不承诺此阶段覆盖任意未来应用的全部汉字。
4. 扩展语义配色：背景、不同层级表面、主/次文字、图标、强调、边框、禁用、错误等。
   原生和 JSON 控件使用同一套主题角色，给脚本提供读取及变化通知。
5. 系统先支持 zh_CN/en，复用归档翻译内容并校正新文案。
   使用稳定翻译 key + 表，更新有绑定的文字、字体和布局；动态数值、输入、页面和 JS 变量保留。
6. 语言、主题、字号偏好异步保存。切换时发生一次文字测量/重排/重绘，日常绘制无持续翻译轮询。
   不保留两套完整界面；共享翻译和字体资源。性能验收记录切换时长、峰值内存和切换后的资源基线。
7. 旧截图标记失效，按需要重新生成最近应用预览，避免语言/主题变了但预览仍是旧状态。

## 原生界面和手势

图一的圆角卡片、状态区、滑块、分组和留白作为视觉参考，适配 320x480，保留当前设备真正可用的功能。
不复制手机上的运营商、飞行模式、投屏等未实现项目。

- 桌面：根据屏宽、字号和触摸目标计算列数，默认紧凑网格；统一图标实际尺寸和风格；名称完整行高，长名有明确策略。
- 快捷面板：顶部时间/日期/设置入口；Wi-Fi/主题等快捷卡片；亮度和音量大滑块；必要时内容可滚动。
  音频/Wi-Fi 后端未接入时，不显示虚假的开关状态。时间无有效来源时保持真实的未校时状态，Wi-Fi 批次接入校时。
- 下拉：按下、方向锁定、跟手、释放判定、收尾、取消完整状态机；移动过程中改变位置和遮罩透明度。
  滑块拖动、面板滚动、收起手势有清晰的事件归属，禁止边拖滑块边关闭面板。
- 设置：顶部机型卡；分组列表；左图标，中间标题/当前状态，右侧箭头或开关；配置细节进入子页。
  基础组件统一尺寸、圆角、按压态和文字层级，不再一屏堆所有滑块和说明。
- 侧边返回：跟手弧形/圆角指示和箭头、进度反馈、松手提交或回弹，未超过阈值不触发返回。
- 底部导航：上滑后释放回桌面；上滑后在有效区域低速停留进入最近应用，停留时间/移动容差可调。
  采用状态机避免一次手势重复触发 Home 和 Recents，触摸取消会恢复界面。
- 最近应用：居中预览卡片、左右吸附、点击恢复、上滑关闭；底部“全部清除”；不显示顶部“最近应用”标题；
  点击卡片外空白回桌面，全部清除仅销毁应用实例，不删除应用注册项或系统桌面。
- 动画优先用 LVGL 原生位置/透明度/有限缩放；预览复用、有内存上限，不每帧截图或采用实时全屏模糊。
  流畅度和内存峰值以板上测量验收。

## 组件边界

系统专用的面板、返回指示、导航和最近应用保持原生实现。
建立轻量共享组件：设置行、开关行、分组卡、快捷卡、滑块、标题栏、对话框、图标与文字样式。
先给 C/C++ 系统使用，再将适合应用的部分映射到 JSON 类型，最终仍创建同一套原生 LVGL 控件。
不引入 Android SDK，不在此阶段复制完整 Android/Material 控件库。

## 后端和应用 API

沿用直接原生接口的轻量结构。系统 UI 与脚本 API 调用同一个后端，不各自维护一份设备状态。
硬件 I/O、扫描、解码、录音和 Flash 保存不在 UI/JS 回调里等待。
快照读取可以同步；耗时命令提交任务，提供请求标识、状态/完成事件、超时与取消规则。

以下是拟议接口分组，不是当前已实现的 API 名称承诺：

| 分组 | 计划能力 |
| --- | --- |
| display | 像素/逻辑尺寸、密度、字体倍率、亮度读取/请求修改 |
| theme | 当前模式、语义色、变化通知 |
| locale | 当前语言、翻译、变化通知 |
| system | 保留已有系统信息查询 |
| power | 电池与供电快照、熄屏时间、熄屏与唤醒 |
| audio | 音量、静音、试听/播放状态、录音电平与短录音测试 |
| wifi | 能力和连接快照、扫描、连接/断开、状态变化 |

事件送到 UI 任务后才进入 JS；跨线程不持有/调用 JSContext。
每个实例的订阅在关闭时移除；排队事件带实例标识避免投递给已销毁环境。
后台合并最新状态，恢复时补一次同步，避免暂停应用因变化通知而持续执行。
主题/语言/字号切换更新控件和绑定，不重建整个 JS 环境。

## 硬件范围与验证

- 电源首批读取 PMIC、电池存在/电量/电压/外部供电/充电状态；不可读字段显示未知。
  自动熄屏是关闭显示背光，不等于 MCU 深睡眠；唤醒首次触摸由系统消费。
  真关机、深睡眠、充电电流配置需要单独确认硬件行为，不当作归档已经实现的功能迁移。
- 音频先建立统一输出与采集生命周期，接入音量/静音和内置音频试听，提供基本短录音回放。
  完整音乐库、流媒体和后台音乐策略另行设计；WAV/MP3 复用已有代码时锁定依赖并保留原生解码。
- Wi-Fi 使用 P4 -> esp_wifi_remote -> esp_hosted -> SDIO -> C6；先核对从机版本，再确定锁定依赖。
  支持扫描、输入密码、连接、断开、IP/RSSI、保存连接、有限重试/手动重试。
  无 C6/握手失败/密码错误不能阻塞进入桌面，也不引发主机重启循环。
  归档中 Hosted 有 constructor 自动初始化问题和延迟初始化处理；迁移时验证实际启动时序。
- I2C 由板级统一管理，PMIC、音频、触摸不重复安装总线；串行化可能冲突的访问。
- 内置 JSON+JS “接口测试”应用分组显示能力、状态、操作结果和变化计数。
  可写接口要实际控制硬件；不可用能力明确显示；切换/关闭后无遗留回调与任务引用。

每批执行适合改动的真实 LVGL/QuickJS 主机验证，检查按压/滑动取消、释放后误点、长文案、大字号、中英切换、明暗对比、
后台/恢复/关闭与对象/定时器基线；硬件部分由用户烧录测试成功路径与故障路径。
