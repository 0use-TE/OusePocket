# 主动断开与异常断线

主动断开此前只调用 terminate；worker 每两秒恢复可连接广播，已配对电脑可能立即重新连接。

修复增加独立的内存状态 reconnect_paused：主动断开先暂停广播恢复、关闭配对窗口和数字确认，再停止广播、取消连接过程并终止当前链路。已经排队到达的成功连接回调也会终止，不对应用发布已连接状态。蓝牙开关与配对密钥保留。

显式连接、开启可被发现、显式打开蓝牙解除暂停；仅搜索设备不会解除。异常断线不设置暂停。此状态不写 NVS，重启后仍按原有蓝牙启用偏好工作。

命令策略、GAP 竞态、应用连接所有权及 QuickJS 绑定回归覆盖此改动。显示刷新周期继续保持 33 ms。

2026-10-20 COM10 已烧录，写后哈希通过。真机从 connected=1 / encrypted=1 点击设置页“断开连接”，断开原因为 0x216（本地主机终止）；每两秒取样、连续八次均 connected=0 / advertising=0 / error=0，bonds=2 保留。证据 `.tools/ble-manual-device-final.log`，观察结束串口已释放。
