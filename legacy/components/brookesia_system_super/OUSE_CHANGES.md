# OusePocket 桌面扩展

来源：Espressif ESP-Brookesia `brookesia_system_super` 0.8.3，上游提交 `e937455b0db1a3e873b1da61d6d13652f3dcc7e2`。保留 Apache-2.0 授权；`.reference/esp-brookesia` 保持原样。主工程通过 `override_path` 使用本目录。

2026-10-14：新增全屏下拉快捷面板。

- 桌面顶部原状态栏保持常驻；应用中原状态栏仍按原规则隐藏。
- 从顶部边缘下滑展开，保留状态栏，覆盖其余屏幕并拦截下方应用触摸，不自动收起。
- 通过 Display 服务调整亮度，通过 AudioPlayback 服务调整音量、静音；打开时读取实际值，服务不可用时禁用对应控件。
- Wi-Fi 展示连接状态，配网和开关仍在 Settings 中操作。
- 从底部 24dp 区域向上滑动收起；关闭按钮也可收起。恢复展开前的桌面或应用，不停止应用。
- 切换前台应用时收起面板；面板内滚动、拖动滑块不触发原来的应用退出手势。

入口：`src/shell_display.cpp`、`src/shell_quick_controls.cpp`、`resource/shell/screens/overlay.json`。新增私有依赖 `brookesia_service_audio`。布局沿用官方 GUI 文档和 LVGL 后端，支持现有主题、语言及逻辑缩放。

构建验证和实机验证分开记录。没有增加通知中心、最近任务列表或蓝牙功能。

同日视觉修正：亮度和音量滑块显式设置 indicator/knob 样式，显示已选轨道与当前位置滑钮；静音和关闭按钮增加显式 2dp 边框、内边距、居中文字和按下配色。

### 2026-10-15：固定分页桌面与快捷面板重做（待实机验收）

- 启动器取消纵向滚动与弹性位移，按屏幕/DPI计算每页固定容量，超出左右分页；滑动与动画期间抑制应用点击。桌面侧边不再触发应用返回手势。
- 快捷面板使用主题配色的圆角图标卡片、水平胶囊滑条和底部短横条；移除关闭按钮及文字提示。Wi-Fi 卡片进入 Settings，配网仍在 Settings 中操作。
- 顶部下拉跟手移动，整次展开触摸由遮罩持有；松手吸附动画完成后才启用控件。滑条独占调节手势，底部 32dp 区域上滑跟手收起，短拉回弹。
- 状态栏只显示电池轮廓和填充量，低电量红色、充电绿色；百分比和充电文字仅在下拉面板显示。
- 主机检查执行实际 Shell 手势分支与吸附方法，并用真实 GUI 解析器/校验器检查明暗主题和三种 DPI。它不替代实机触摸、动画流畅度及外设验证。

资源生成：`tools/generate-shell-controls.py`（需要 Pillow）；回归检查：`tools/test-shell-controls.py`。

### 2026-10-15：主题重启提示与五格电池（待实机验收）

- 下拉主题按钮改为与 Settings 相同的保存偏好模式，显示当前选择及“重启生效 / 待重启”。选择新主题后弹出“立即重启 / 稍后”；再切回正在使用的主题可取消待生效选择。
- 立即重启复用 System HAL，保留现有背光关闭处理；重启接口不可用或失败时提示错误。Settings 恢复前台时读取同一份主题偏好。
- 电池参考乐鑫旧版 Phone 的按档选择图标机制，改为横向五格：0% 空格、1–20% 一格，依次递增至 81–100% 五格。低电量（≤20%）红色，充电绿色并叠加闪电，未知电量独立问号图标。状态栏不显示百分比，下拉保留具体电量。

### 2026-10-15：主题文字与图标适配（待实机验收）

- 主题快捷按钮显示“主题 / Theme”，不显示 Light/Dark 名称；待生效时保留“待重启”，点击后的重启确认继续保留。
- 快捷图标使用 contain 完整缩放。五格电池、充电和未知图标分别提供浅色/深色资源，状态刷新按正在运行的主题选择。时钟提高文字对比度，滑条两端留出滑钮边距。
- 主机检查使用真实解析器/校验器及 LVGL 布局夹具，覆盖中英文、两主题、75/100/125% 缩放。夹具不是完整设备 GUI 后端，外设与重启稳定性需实机验证。

### 2026-10-15：支持桌面之后注册网络服务（待实机）

Wi-Fi/SNTP由板级代码在桌面就绪后注册；Shell通过现有时钟定时器补齐晚到服务的绑定及事件订阅，避免启动时服务缺席导致状态栏永久缺失。已建立的订阅不重复创建。启动顺序及验证见 `docs/19-deferred-wireless-startup.md`。
