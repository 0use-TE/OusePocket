# 0.30.0 触摸与蓝牙入口

包含 0.29.1 闹钟数据库/快照的 PSRAM 迁移（16,528 字节），锁与闹钟线程栈仍内部。原生 API 33，JS API 1。

## 应用触摸

开放 pointerdown/move/up/cancel，坐标相对按下时控件左上角，dp/px 跟随页面；提供累计合并后的 dx/dy、单调 timeMs、固定 pointerId=1。普通点击/方向滑动接口兼容，注册原始触摸的控件采用按压捕获，不同时使用该控件的原生滚动/方向 swipe。

每实例八槽（位于实例的 PSRAM），移动合并、至少 16 ms 派发间隔，不扩张普通事件队列。预留结束槽；队列不足时拒绝新手势。失焦、导航、关闭、系统接管清理捕获；故障时由原生 HID 清理兜底，不能要求已故障 JS 再处理取消。系统底部护栏和侧滑接管沿用现有壳层。

鼠标应用移除松手后才突发移动的方向 swipe，采用连续位移；左右键可按住拖动，松开/取消释放。按住期间以有界低频更新报告，不让两秒无松键保护把合法长按误释放。网易云不显示“播放中/已暂停”，控制按钮固定“播放/暂停”；本地动画不是电脑播放器状态反馈。

## 系统蓝牙

下拉短按开关蓝牙，长按直接打开设置第 13 页。状态栏关闭时隐藏；开启未连半透明，连接后正常显示。采用 20dp 图形绘制，避免字体图标切割，不显示播放状态。

快捷卡采用三行两列：Wi-Fi/蓝牙、声音/电源、主题/USB OTG，下方保留音量与亮度滑杆。USB OTG 短按总开关（不擅自开启网络共享），长按设置第 10 页；状态区分不可用、关闭、未连接、已连接。只控制原生 OTG，不影响 COM10 的 CH343 下载串口。总开关沿用原服务的运行期状态，不新增持久化协议。

## 验证范围

主机回归增加有界指针缓冲、千次移动合并与位移、保留终止槽、代际隔离、鼠标拖动/取消测试。普通事件仍在 JS 工作线程调用，不在 LVGL UI 线程运行应用 JS。端到端移动速度还受 BLE 连接间隔、主机输入处理和屏幕刷新影响。

50 ms 是脚本片的累计 CPU 硬限，不是每条事件新领 50 ms；12 ms 是回调返回后的软让出阈值；墙钟超时另计。异步网络/存储等待不等于持续消耗脚本 CPU。
