# 0.13.0 下拉交互、录音修复与音乐/闹钟

本轮按用户选择完成已有 PCM16 WAV 能力上的音乐、播放列表及后台控制，补齐闹钟应用，同时修复下拉面板和最近应用交互。系统、硬件工作任务和音频搬运仍原生，业务应用为 JSON＋JS。固定 ESP-IDF 6.1 和所有外部依赖版本，分区、显示修复、字形与默认倍率保持。

## 原生界面

快捷面板新增独立音量滑条，原声音快捷项直接切换静音，不再跳转设置；亮度滑条继续保留。音量大于零时解除静音，修改继续走现有异步偏好保存。通知在左、快捷面板在右，展开后横向拖动可切换；竖向列表滚动和顶部/底部上滑关闭保持。滑条触摸优先，不把调节亮度/音量的横拖当成切页。

最近应用容器覆盖到屏幕顶端，横向卡片条允许子对象向外绘制。卡片原始静止位置保持，上滑时可进入状态栏区域；状态栏以 160/255 背景不透明度覆盖在预览上，时间和电量仍可读。退出最近应用恢复不透明状态栏。回桌面预览动画同样使用半透明状态栏。既有横滑卡片、上滑关闭和全部清除逻辑保持。

## 录音回放

固定 IDF 6.1 的 P4 I²S 默认 MONO 配置为 BOTH 时隙。TX 依赖此配置将单声道复制到输出，RX 默认同时收两个时隙，却被原代码按每帧一个样本计数，与用户描述的慢速低音现象吻合。修复仅将 RX 显式设为 LEFT；TX 保留 BOTH，不更改 16kHz、16bit 或原 codec/双工开关顺序。

原生读写现在核对 DMA 实际传输字节数，短读/短写按错误收尾，避免把不完整缓冲当作成功。录音及回放输出样本数、PCM 时长、经过时长和 RX 时隙日志；经过时长包含等待，不能称 CPU 时间。保留启动预填静音、错误回滚和单 codec 所有权。

主机检查运行真实 board_audio.c，通过驱动替身确认 TX BOTH、RX LEFT，48,000 样本分别录放约 3 秒，短传输失败且资源释放。替身不能证明实机声学效果，仍需现场录人声听音确认。

## 音乐

安装 `dist/bpk/music.bpk`，需要本版固件。首页为当前曲目、状态、进度、播放/暂停/停止、上一首/下一首和模式。列表含不可删除的 30 秒包内片段，另可保存最多七个 HTTP/HTTPS WAV 地址。顺序播放到列表末尾结束；单曲循环重播当前曲目。进度为只读，尚无 seek。

列表、选择及模式保存在应用私有存储，写入合并串行；普通关闭、重启和同 ID 更新保留，卸载删除。当前任务彻底结束后才换曲。失败、用户停止和取消不当作自然结束；自然结束依据任务成功终态。系统结束后台许可后不自动重新申请。

用户开始或继续播放时申请 `music-playlist` 后台原因；暂停、停止、失败、列表结束及关闭 JS 时结束许可。保留实例并获后台许可时可自动换曲；关闭应用后原生当前曲目继续，关闭实例后不自动换曲。重新打开可暂停/继续/停止当前会话。后台预算仍为 4ms，未扩大或绕过保护。

原生媒体服务负责 `ouse.media` 持续通知，播放/暂停/闹铃抢占时更新，生产任务及 codec 均释放后取消。即使 JS 已关闭也能清理通知。通知点击返回播放控制；系统活动页仍可停止原生任务。

示例为 Beethoven《致爱丽丝》、V Gao / Gaodifan 的录音，来源 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:FurElise.ogg)，页面明确标注公有领域和 CC0。取开头 30 秒，低通后转为 8kHz 单声道 PCM16 并淡入淡出，480,044 字节，断网可播放。来源/处理记录在 `apps/music/AUDIO-LICENSE.md` 及包内 `assets/license.txt`。音源不编进固件；低采样率用于遵守包大小，不宣称高保真。

为容纳片段，binary 单项、text＋binary 合计和原生包内媒体上限改为 512KiB，总 BPK 仍不超过 512KiB；图片 128KiB、text 单项 16KiB、JS 堆和其他配额不变。板端、运行时、Python 打包和编辑器发现校验同步。原生资源及媒体各复制一份大资源，需计入额外内存。未增加 SD、MP3/AAC/FLAC 或解码依赖。

## 闹钟

安装 `dist/bpk/alarm.bpk`，最多四个闹钟。提供列表、新建/编辑名称与时分、重复星期、启用/关闭、删除；不选星期为下一次该时间的一次性闹钟。列表显示启用、关闭、响铃或错过，正在响铃时提供停止和贪睡五分钟。点击系统闹钟通知返回首页。

全部安排与触发由原生持久闹钟服务负责，不申请后台 JS。应用关闭和重启保留安排。使用固定北京时间 UTC+8，时间无效时拒绝保存并提示连接 Wi-Fi 校时；不提供关机或深睡唤醒，不自动处理 DST。

新增 `Ouse.alarms.setEnabled(id, boolean)`，返回任务 ID 或 false。关闭持久保留规则，落盘成功后停止当前响铃；启用重算将来发生点，已过期的一次性闹钟需在编辑页重新保存。成功/失败通过公共任务终态反馈，不将提交成功当落盘成功。启用状态使用既有磁盘 schema，未迁移或擦除闹钟文件。分类 service-test 增加对应操作。
