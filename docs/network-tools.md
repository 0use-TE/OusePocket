# 网络工具与倒计时提醒

适用 Core 0.23.0 / 原生 API 26。只需安装应用包，不需要重新烧录固件。

## 网络工具

`apps/network` / `user.network`：右上角图标打开模式选择。

Ping 主界面显示当前 Wi-Fi 名称、IPv4 和信号强度；右上角菜单的“网络信息”面板显示连接状态、Wi-Fi、IP、信号和校时状态，每两秒刷新。当前脚本接口没有提供网关、DNS、MAC，不显示猜测值。日志按内容紧凑排列，不再均分剩余高度；内容超出结果区时可滚动。

- Ping：输入 IPv4 地址或主机名，执行三次探测，显示回复耗时和回复数。
- HTTP：输入 `http://` 或 `https://` 地址，执行 GET，显示状态码、耗时、响应字节数和截取的正文。
- WebSocket：输入 `ws://` 或 `wss://` 地址，连接后发送文本，接收文本或二进制消息的 UTF-8 预览。
- MQTT：输入 `mqtt://` 或 `mqtts://` 地址；账号入口可填用户名、密码；输入主题后订阅或发布。当前固定 QoS 0、不保留发布消息。

不默认连接公共 WebSocket/MQTT 服务，不在日志或私有存储保存密码。HTTP 默认测试百度 HTTPS 的 robots.txt，避免主页超过内核的 32 KB 响应限制；Ping 的默认 `192.168.1.1` 需按实际网关修改。结果区域保留最近四条截取记录，不是抓包或完整响应查看器。

切换模式、回桌面、关闭应用会取消请求或关闭连接；返回后不自动重连。HTTPS/WSS/MQTTS 保持证书验证，需要系统时间正确。网络断开、协议不匹配、连接资源不足均显示失败，不降级 TLS。

## 倒计时

Core 0.24.0 到时调用 `Ouse.audio.alert()`，按半秒响、半秒停持续嘀声，直到点击“确认”，并只发布一次“时间到”通知。每秒检查并在音频繁忙时重试，不重复创建未完成的提醒任务。响铃期间保留后台活动，返回应用或打开通知显示确认框。确认时取消本应用的音频任务及重试定时器，不使用全局停止音频，避免误停其他应用。提醒与音乐混合，音乐平滑压到 25% 并在确认后恢复；遵守系统音量、静音、录音和 USB 音频占用规则。

运行中的倒计时持有后台活动，可在其他应用中到时提醒；显式关闭倒计时或重启会取消，不宣称关机或关闭应用后仍能提醒。计时改用单调运行时间，避免系统校时或 JS 回调延迟导致累计偏差。

系统会抑制前台应用自己的通知横幅；倒计时在前台到时仍会发布通知、尝试播放提示音，但不叠加自己的顶部横幅。在其他应用或桌面到时则按系统通知策略显示。

## 离线验证

```
node tools/test-countdown-app.cjs
node tools/test-network-app.cjs
python tools/test-ouse-app-packages.py --apps countdown network
```

离线长连接行为测试使用模拟服务。2026-10-18 已安装两个应用到 Core 0.23.0 真机：后台 30 秒倒计时出现“时间到”横幅；百度 robots.txt HTTPS 返回 200 / 2814 字节；局域网 Ping 三次回复；以同一网络工具脚本驱动的临时测试包完成 WebSocket 回显、MQTT 订阅及发布回显。临时包、测试服务器与防火墙规则已移除，运行时 errors=0、DBG_CHECK ok=1。

短提示音的触发调用已做行为测试，远程测试不能代替现场确认扬声器听感。WSS/MQTTS 的真实服务、证书和账号组合未在本轮验证。
