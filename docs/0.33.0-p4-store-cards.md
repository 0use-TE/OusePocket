# 0.33.0 P4 商店卡片

本轮只调整 P4 客户端与所需图片更新接口，不重做 Web 商店。P4 商店移除搜索和上一页/下一页按钮；分类选择下方为两列图标卡片，上下滚动加载。每次取 6 项，最多保留 12 项，前后滚动复用卡片槽；网络取消及源切换使用请求代次，旧请求不会覆盖新页面。

源入口在连接期间始终可点，进入时取消旧索引与图标请求；源页面仅地址输入框和“连接”按钮，没有说明小字。安装仍采用系统确认。

原生 API 37 新增 `Ouse.ui.setImageData(imageWidgetId, oic1ArrayBuffer)`。只更新该控件引用的包内 ARGB8888 图像槽，不创建无限图片资源。接受最大 96×96 OIC1 BGRA，将像素缩放到既有槽尺寸，暂存在 PSRAM；UI 线程执行缓存失效、交换和旧像素释放，同槽未消费更新覆盖释放，实例关闭时清理。非法头、长度、尺寸被拒绝，关闭/故障实例拒绝更新。远程图标失败使用占位图，不中止应用列表。商店使用 12 个 48×48 图标槽，逐项下载，不依赖 SD 卡。

COM10 已仅更新 P4 应用区和商店 BPK；30 项回归通过，包括真实 QuickJS/LVGL 图片交换、反复替换与异常数据拒绝。真机显示真实图标卡片和详情，切换“生活日常”仅显示记事本/天气；使用延迟 30 秒响应的测试服务模拟云端卡住，连接期间点源能立即进入地址/连接页，旧请求取消后不覆盖配置页。112 控件/一个上下文时内部空闲 148,639 字节，堆完整性通过、运行错误 0。连续滚动的多窗口追加/前插由行为测试验证，真机当前源只有四项。

后续商店 1.2.1 修正源按钮高度和奇数卡片拉伸：保留空列占位，118 控件，无需再次更新固件。云端 1.1.0 已改用 SQLite 索引与版本记录，并增加浅色 App Store 风格；对象文件仍独立存储，迁移及备份见 `cloud/store/README.md`。
