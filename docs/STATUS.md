## 保持的架构

- 显示、触摸、电源、音频、Wi-Fi、存储、安装和设置保存由原生 C/C++ 实现；UI 读取缓存、提交请求，耗时工作在各自后台任务执行。
- 桌面、手势、最近应用和设置使用原生 LVGL，共享主题、dp/sp、语言、字号与控件。
- 独立应用使用 JSON＋JS，经受控 API 访问原生服务；后台暂停 JS，恢复时补发合并的设置通知。
- 更新/卸载先在 UI 锁内清除旧实例、图标对象和缓存，再允许安装任务释放旧包；安装任务不操作 LVGL。
- 不让任意 JS 在后台持续运行；本版不开发音乐、倒计时、闹钟后台业务 API。

固定依赖仍为 IDF 6.1.0、LVGL 9.5.0、BSP 2.0.2、Adapter 0.6.4、QuickJS-NG 0.14.0、Hosted 2.12.3、Wi-Fi Remote 1.6.5、LittleFS 1.22.3。CPU 400 MHz、PSRAM 200 MHz、双核、XiP 及真实 LCD/Wi-Fi 保留。
