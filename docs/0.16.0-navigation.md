# 0.16.0 系统导航

设置 → 外观 → 系统导航，可选择「全面屏手势」或「三键导航」。即时生效，无需重启；选择异步保存到 NVS。旧设备没有 `navigation` 键时沿用全面屏手势；非法旧值回退到手势模式。

- 手势模式保留原来的底部上滑回桌面、停顿进入最近应用、边缘滑动返回和跟手横条。
- 三键模式按从左到右排列：三角返回、圆形主页、方形最近应用。点击最近应用键可进入/退出最近应用，主页键回桌面，返回键优先关闭键盘、对话框、设备弹层和系统面板，再交给应用返回逻辑。
- 三键模式禁用底部上滑导航和两侧返回手势；顶部下拉通知/快捷设置及最近卡片滑动关闭保留。下拉系统面板时仍可使用导航键。
- 三键导航区高 40 dp，手势导航区高 24 dp。切换时调整桌面、应用宿主与所有已创建应用根节点的高度，清理旧预览，避免按键遮挡应用底部。桌面仍为每页 12 个应用。
- 图标使用轻量几何绘制，不依赖额外字体或图片；导航图标适配深浅主题。

核心 C API 17：设置状态增加 requested/saved navigation 字段；BPK/JS API 仍为 1。

## 验证

主机测试 `python tools/test-ouse-system.py` 覆盖旧键缺失、非法值、重启读回、即时 requested 状态、异步保存、与其他设置合并、提交失败和重试；PSRAM 和 JS 应用回归测试通过。ESP-IDF 6.1 构建通过。

设备测试脚本：`python tools/test-device-navigation-modes.py --port COM5`，要求固件开启 MCP 设备调试、安装串口依赖并独占串口。脚本从设置切换三键模式，检查返回/主页/最近应用，切回手势并运行原生手势回归，最终回到桌面。

跨重启检查分两步：先执行 `--stage buttons`，等待设置保存并重启设备，再执行 `--stage restore`，验证启动后仍为三键模式，最后恢复全面屏手势。默认 `--stage all` 不包含物理重启验证。
