# 0.21.0 手机式相机、相册与无声录像

- 相机不再显示应用名、重试按钮和状态小字。预览自动填满底部控制区以上的空间，中心裁切铺满，不拉伸；保存文件仍保持传感器原始比例。
- 底部左侧为最近照片/视频缩略图，点击打开已安装相册；中央为圆形快门，右侧切换照片/录像。录像时快门内部变为红色圆角方块，上方仅显示 REC 与时长。
- 相册取消标题、刷新、文件名和每张图片下的查看按钮，使用三列缩略图网格，直接点击预览。新文件排在前面，每组十二项，多于十二项时显示上一组/下一组箭头。图片保留完整比例；系统录像可直接播放、重播。侧边返回回到网格。

## 原生接口

`Ouse.camera.record()`、`recordStop()` 返回异步任务 ID，完成事件使用现有 `Ouse.tasks.onComplete`。需要 camera 和 files 权限，且仅限当前摄像头所有者、可见应用。get() 新增 `recording`、`recordedMs`。

`Ouse.photos.list(offset)` 返回至多十二个按时间倒序的 Pictures/JPEG、AVI 文件；条目新增 `video`。open(path) 对系统录制的 MJPEG AVI 自动播放，get() 新增 `playing`；stop() 停止本实例播放。原生图像扩展为 @thumb0 至 @thumb11。offset 上限 4096；超过三秒的目录扫描退出。

`Ouse.openApp(id)` 异步请求系统打开已安装应用；只接受可见、未关闭/故障实例的请求，应用切换在 UI 线程执行，不在 JS 线程调用 LVGL。

## 录像边界

采用硬件 JPEG 编码、MJPEG AVI 单视频流，**没有音轨**，不占用麦克风。采集与录像为 1280×960，目标上限 10 fps，文件头按实际帧数与实际时长写入帧率。文件较 MP4/H.264 大，不宣称为 MP4。保存到 SD 卡 `Ouse/Pictures/VID_*.avi`。

编码输出、帧索引和视频播放输入缓冲均放 PSRAM；持续拍摄和文件操作均在原生工作线程。每帧独立编码，AVI 含 movi 和 idx1 索引；停止时回写长度、帧率、帧数并同步关闭，再将独占创建的 .part 重命名为最终文件。正常退后台、关闭、任务取消和休眠会停止并收尾，不会继续后台偷拍。断电或物理拔卡不保证完整保存，未收尾 .part 不出现在相册。

单段最多 30 分钟、18000 帧，或约 1 GiB AVI；任一限制达到即收尾。开始至少需要 8 MiB 可用空间，录制预算保留 4 MiB 给索引和文件收尾。并发写入或突然断卡仍可能导致 I/O 失败，不能将预算当作空间锁。SD 不可用时不退回内部 Flash。

播放只保证系统生成的标准布局 MJPEG AVI，不提供任意外部视频或有声视频兼容承诺。JPEG/AVI 长度、分辨率、分块边界在原生解码前验证。
