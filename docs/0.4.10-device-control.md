# 0.4.10：真机控制、板上测试和底部手势

0.4.9 只增强异常诊断，没有修改 Wi-Fi 或修复根因。其 300 秒采集期间包含应用开关、主题切换、设置保存和熄屏唤醒，没有捕获到 panic；这不是稳定性修复证明。原始记录在 `.tools/diagnostics/live-core1-049/`。

## 实现

- 板子继续由现有 OPK1 串口服务独占 UART0 RX。增加显式 DBG 命令，没有网络监听器、额外 USB 轮询或常驻测试任务。可用 `CONFIG_OUSE_DEVICE_DEBUG=n` 关闭控制入口和测试。
- 外部操作通过 `ouse_core_post_ui()` 投递到 LVGL 线程，使用实际注册的触摸 indev；点击、移动、抬起经过同一套 LVGL 控件和系统手势处理。触摸驱动的中断读取逻辑保持原样，模拟按住期间只覆盖输入数据，10 秒无新指令自动释放。
- 状态接口读取前台应用、主题、语言、字号、密度、最近应用和下拉层；控件树提供文字、类型和坐标，限 160 个节点，不导出输入框的内容。
- 截图在 LVGL 线程抓取当前系统 screen 的 RGB888 绘制快照并复制所有权；JPEG 在串口工作线程编码。没有常开视频推流。像素表示 LVGL 的 UI 渲染结果，不是摄像头照片或 LCD 回读。
- 电脑按块读取 JPEG/控件树，并校验长度与 CRC。普通日志和协议回复共存。工具只有一个串口读取线程，每个字节先落盘，再处理 ACK；检测 panic 后停止输入，继续接收完整转储。数据文件含 UART、按次操作时间和固件 ELF/MAP/配置。
- MCP 在电脑端运行，以 stdio JSON-RPC 暴露设备工具。板端维持简短的串口命令，不承载 JSON-RPC 网络服务。当前任务也可直接使用同一套 Python 客户端操作设备，无需先配置 MCP。

## 手势

底部 36 dp 内开始上滑，超过 8 dp 取得系统手势控制。上滑超过 32 dp 后松手，回桌面；尚未达到距离则恢复原应用。上滑后停住约 160 ms，即在手指未抬起时打开最近应用，允许约 10 dp 的抖动。触发后等待抬手，不把此次抬手当成卡片点击。生成预览快照的时间不计入停留时间，避免慢帧误触发。数字是本产品的交互参数，不声称是某个 Android 版本的原始阈值。

## 使用

在仓库根目录执行，使用已安装 pyserial 的 Python：

```powershell
python tools/device.py --port COM10 state
python tools/device.py --port COM10 open ouse.counter
python tools/device.py --port COM10 tree
python tools/device.py --port COM10 tap 160 250
python tools/device.py --port COM10 swipe 160 474 160 380
python tools/device.py --port COM10 swipe 160 474 160 380 --hold 220
python tools/device.py --port COM10 screenshot .tools/screen.jpg
python tools/device.py --port COM10 tests
python tools/test-device.py --port COM10 --rounds 10
```

坐标以 `state` / `tree` 的实机结果为准。运行时不要让其他串口监视器抢读 COM10。

板上 Unity 测试包括密度换算及堆完整性、输入边界、快速上滑回桌面、上滑按住并抖动打开最近应用、短滑取消。断言在串口工作线程执行，UI 操作交给 LVGL 线程，避免跨线程 longjmp。另有电脑驱动的真机集成测试：读取控件树定位按钮、实际点击使 JS 计数增加、在手指仍按住时断言最近应用出现、截图、重复应用切换。它们不能代替所有音频、网络、安装和长期稳定性测试。

## MCP

启动命令：`python tools/device-mcp.py --port COM10`。支持 `initialize`、`ping`、`tools/list` 和 `tools/call`，工具为：

`device_state`、`device_tree`、`device_screenshot`、`device_tap`、`device_swipe`、`device_open_app`、`device_home`、`device_test`、`device_stress`。

通用 MCP 客户端配置示例见 `device-mcp.example.json`；这只提供配置示例，没有改动本机 Codex 或其他客户端的全局配置。MCP 连接和命令行工具共用一个设备时需先释放旧连接。
