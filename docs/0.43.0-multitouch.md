# 0.43.0 双指输入（Native API 45）

Waveshare LCD35 的 FT6336 接入两路独立 LVGL pointer 输入。此板最多同时两指；配置中的 MAX_POINTS=5 不代表硬件支持五指。

应用继续使用 `pointerdown`、`pointermove`、`pointerup`、`pointercancel`，事件的 `pointerId` 为 1 或 2。编号属于应用输入槽，并非硬件 track ID；不要假定每次按下都从 1 开始。需要同时操作同一节点时，应用应按 pointerId 保存各自状态。不同节点可独立按住，例如左侧摇杆与右侧攻击按钮。

各触点独立捕获节点、局部坐标原点、移动合并队列与释放状态。松开一指不会结束另一指；移出控件后仍能收到终止事件。应用暂停、关闭、显示方向变化时取消已有触点。唤醒屏幕的触点被消费，不穿透到应用。

## 测试入口

接口测试 → 控件与输入 → 双指输入 / Multi-touch。页面显示两个触点区域、各自 ID 和坐标、当前及最高同时按下数量，支持横竖屏。

## 验证

- `tools/test-multitouch.py`：真实 LVGL 与 QuickJS，验证两路输入、独立坐标、单独释放、移出释放、取消及复用。
- `tools/test-device-multitouch.py --port COM10`：通过 `DBG_TOUCHES slot:x:y:down` 向两路实际 LVGL 输入注入，横竖屏验证同时按住、独立释放、移出释放及后台取消；运行结束释放两路输入并关闭串口。
- 内核与平台运行时回归通过；最终固件编译、COM10 烧录及哈希验证通过。设备运行时 errors=0、dropped_events=0。

自动注入验证输入分发链路，不代替两根真实手指对 FT6336 采样的验证。测试页保留供手动检查。

调试输入租约十秒未刷新会自动松开，避免调试进程意外退出留下长按。原有 `DBG_TOUCH` 保持第一路语义。
