# 0.5.0：应用框架第一阶段

本阶段覆盖脚本执行与绘制分离、受控后台执行、统一控件和样式入口，以及系统软键盘。依赖版本、真实 LCD 刷新等待、Wi-Fi、分区与已有用户数据保留。探索阶段不维护旧页面或旧 API 的兼容分支，BPK 仍只有一种格式。

## 执行边界

一个系统脚本任务拥有所有应用的 QuickJS Runtime/Context，应用之间分开分配 JS 堆与全局变量。LVGL 任务只创建和更新控件，通过有界事件队列把输入发送给脚本任务。JS 的界面设置修改纯数据模型，由界面任务消费，脚本不进入 LVGL。

打开应用异步初始化页面和脚本。关闭、更新、卸载立即撤销可见界面与输入，脚本任务随后销毁上下文。实例保留独立的源码、资源副本与引用计数，卸载包后后台清理仍有自己的有效数据。

前台优先调度，后台单次执行限额较小。计时器按到期回调工作，系统任务等待通知或下一次调度时机；不会持续空转。JS 执行超时只使该应用出错，这不是任意原生 C 调用的强制抢占。

## 应用生命周期

清单可声明：

```json
"capabilities": { "background": true }
```

默认应用离开前台就暂停 JS，保留变量和上下文。仅声明能力不会自动运行；应用需要调用 `Ouse.background.begin()`，工作结束后调用 `Ouse.background.end()`。`isActive()` 返回当前申请状态。

`Ouse.lifecycle.get()` 返回 `state`（foreground/background/suspended）、`visible`、`runnable`、`backgroundAllowed`、`backgroundActive`；`onChange(callback)` 订阅变更。原生应用管理器负责可见性，脚本调度器负责能否执行，两者相互独立。关闭卡片、清除或卸载应用会结束 JS 后台工作。

后台应用调用 Home 或请求输入焦点不会抢走当前前台。后台只更新模型，界面恢复可见时同步模型。普通挂起期间计时器不追补回调风暴。闹钟、定时唤醒与音乐媒体会话尚不在本阶段；不可依靠 JS 存活实现重启后闹钟。

## 控件和样式

这一阶段提供 container、label、button、slider、image、textInput、switch、checkbox、dropdown、progressBar、spinner、arc。不是完整 Brookesia 控件迁移。

所有控件沿用同一套 dp/sp、主题、布局和事件入口。`Ouse.ui` 提供 setText/getText、setValue/getValue、on、setStyle、focus/blur。事件为 click、change、focus、blur、submit，可用 `on(id,event,null)` 解除监听。

样式通过 `style` 和 `Ouse.ui.setStyle(id, style)` 设置：backgroundColor、textColor、borderColor、borderWidth、radius、opacity、textAlign、hidden、disabled、flexGrow。显式颜色属于应用，未指定项使用系统语义样式。复杂 Android 列表项、工具栏、底部弹层等组合控件，以及 table/keyboard/canvas 等完整接口留在后续阶段。

## 系统软键盘

键盘是原生系统服务，JSON 应用使用 `textInput`，不各自创建键盘。示例：

```json
{
  "type": "textInput", "id": "name", "width": "fill", "height": 44,
  "placeholder": "Name", "maxLength": 64,
  "inputType": "text", "keyboardMode": "resize"
}
```

inputType 为 text、number、password。keyboardMode 为 resize（默认，缩小可用页面并滚动输入框）、pan（上移页面）、overlay（保留布局，允许覆盖）。屏幕底部保留 Home 手势区。返回先隐藏键盘，再次返回才执行页面导航；切换、关闭应用或拉开快捷面板也会收起键盘。收起时恢复原尺寸、位移和滚动位置。

原生 Wi-Fi 的 SSID、密码框共用该键盘服务。密码值不导出到控件树。当前键盘支持英文、符号、数字和密码输入；中文拼音的组合文字、词库和候选栏待实现，中文显示字体不等于中文输入法。

`Ouse.display.get()` 返回当前应用实际 contentWidthDp/contentHeightDp，以及 keyboardVisible、keyboardHeightDp、keyboardInsetDp；键盘或可用区域变化通过 display.onChange 通知。覆盖与平移模式不缩小内容区，因此 inset 为 0；后台应用不会读到另一个应用的键盘状态。
