# 0.46.2 合并审查

2026-10-27。审查目标：将 `codex/native-elf-runtime` 的原生 ELF、游戏计算、相机/相册、Wi-Fi 和导航改动整合到 `master`。

## 修复的兼容缺口

相机 1.3.0 声明 `minNativeApi: 48`，但早期 0.46.0 / API 48 固件尚未为放大实时预览关闭双线性过滤。在该固件上安装新相机可能重现 CPU 饱和与 task watchdog 告警。

0.46.2 将优化后的实时图像行为纳入 Native API 49；相机 1.3.1 要求 API 49。既有 API 48 游戏计算、相册接口和 ELF ABI 保持兼容。包解析测试使用同一生产解析器分别编译当前 API 和旧 API 48，验证新版相机在当前固件接受、旧固件拒绝。

## 审查与回归

重点检查 ELF 表/重定位边界、原生任务生命周期、Wi-Fi 关闭优先级与 STOP 事件屏障、SD 单扇区 CRC 回读验证、拍照原子提交、稳定缩略图槽位、全屏导航和相机预览裁切。

修复了旧测试夹具的接口漂移：权限测试误提取相邻函数、计时器缺少帧字段、SD 图像 include 越界提取、蓝牙/文件打开应用缺少当前接口、发布日期写死、缩略图固定为旧 14 槽。新版包测试使用生产图像名称列表，并实际验证最后一个缩略图槽及权限隔离。Wi-Fi 旧断言按当前有限退避重试时序更新，默认同时运行原有故障场景和任务内核中断场景。

统一门禁 `python tools/test-regression.py` 扩展为 47 组，涵盖内核/权限/文件/协议/HTTP/媒体/闹钟、应用包/错误页、Wi-Fi、相机、C++ 游戏计算、ELF、原生游戏控制、Hosted 内存、LCD/DMA 与游戏调度。修正 `--only` 的递归依赖展开，并将 QuickJS 库生成放在使用它的图像测试之前。原生计算测试包含随机批量、缓冲别名与非对齐输入、六种武器状态一致性；ELF 验证包含 10,000 次畸形输入扰动。

主机闹钟持久化测试曾偶发一次断言失败，单独连续运行 30 次通过；增加了宿主 Windows rename 失败时的错误码诊断。该记录没有作为固件问题已复现或已修复的证据。

完整旧 `tools/test-ouse-runtime.py` 单体宿主夹具的依赖迁移仍是已有技术债，未宣称该命令通过；本次统一门禁通过独立的真实 QuickJS/LVGL、生产代码专项和前次实机检查覆盖相关路径。未进行所有外设组合或无限期浸泡，不将本次审查表述为系统不存在任何问题。
