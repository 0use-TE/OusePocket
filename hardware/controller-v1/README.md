# OusePocket 上屏下键控制器 V1

已确定操作件：ABXY、双轴摇杆（带按下/L3）、十字键、Menu、Start；没有 Select。

主机横屏嵌入上半部，整机纵向握持。所有坐标以正面观察：X向右、Y向上、Z朝使用者；前壳正面Z=0，单位mm。

## 打开与查看

- `controller-v1.FCStd`：FreeCAD 1.1 装配，零件按外壳、主机、PCB、元件、按钮帽、背部连接和螺钉分组，可以单独隐藏或做后续布尔编辑。
- `controller-v1-assembly.step`：通用装配实体，不含电气布线与真实螺纹。
- `front.png`、`assembly.png`、`rear.png`、`inside.png`、`exploded.png`：正面、斜视、背面、内部和爆炸示意。
- `dimensions.png`：布局和高度链说明。
- 每个打印件都有单独的 STEP 和 STL。STL 单位mm，导出时居中并将最低面放到Z=0；这不代表已确定最佳打印方向，特别是前壳、十字键和摇杆帽需在切片器检查支撑。

这是机械试装设计，不是已实物验证的生产定稿。PCB仅有板框、开孔和安装位置，元件以外廓及操作尺寸建模，没有布线、焊盘或真实内部机构。

## 元件选型

### 十字键、ABXY、Menu、Start：Alps Alpine SKHHAJA010，10个

厂家资料：https://tech.alpsalpine.com/e/products/detail/SKHHAJA010/

6.0×6.0×4.3，顶部按压，动作力0.98N，标称行程0.25；厂家图纸给安装高度4.3±0.2，推杆直径3.5。4个方向＋4个ABXY＋2个功能键共10个。轻触开关与外部打印按钮帽分开。

PCB顶面Z=-8，开关未按下顶面Z=-3.70；按钮顶柱底面Z=-3.55，名义松开间隙0.15。按钮先走0.15空隙，再走0.25开关行程，总行程0.40。前壳导向环的台阶作为名义行程止挡。

由于开关高度、铜柱及打印件存在公差，0.15不能理解成所有实物天然都有的间隙。按键板采用M2圆铜柱15mm＋名义1.0mm调整垫片；增减垫片调整整个板位。必须用实际开关试配，确认不预压、能触发、止挡不过压。`HeightShim*.stl`是1mm样件；其他厚度可从STEP调整。十字键有独立球面支点和开关避让孔，并按四方向、四斜方向检查外壳活动空间。

### 摇杆：Alps Alpine RKJXV122400R，1个

厂家资料：https://tech.alpsalpine.com/e/products/detail/RKJXV122400R/

选当前标准品RKJXV122400R，不采用厂家列为不推荐新设计的RKJXV1224005。10kΩ、自动回中、带中心按下；外廓18.2×21.7×11.2，每方向最大23°。中心按下标称0.4，厂家范围0.1～0.9，因此空间检查覆盖0.9。

厂家轴图为直径4、双平面距3；轴顶至安装基准18.95。模型轴顶Z=0.15。自制摇杆帽的双平面孔名义4.1×3.1，有限长开槽形成弹性夹口，最终松紧需先打印孔径试样。摇杆帽头部直径20，底部Z=6.5、顶部Z=9.5，较高的位置用于保证全方向倾斜并按下时不擦面板。摇杆帽和模块内部枢轴不是厂家CAD；检查把枢轴高度按PCB以上6～11.2范围取样，不能替代实际零件的活动试配。

厂家PDF与轴尺寸图已保存在 `references/`，原网页链接和查阅日期见 `sources.json`。

## 固定和连接

1. 主机从后方装入前壳，由前框边缘限位，显示区保持开放。
2. 上压条和下固定桥通过M2×8螺钉固定在前壳螺柱上；四块1mm软垫对应参考模型的脚垫位置，夹持力落在原壳/脚垫区域。
3. 主机四周采用较宽的侧面访问带，背面上半部开窗，避免依赖未确认的具体USB、SD和按键开孔坐标；摄像头也保持露出。
4. 按键板用5根M2圆铜柱固定，铜柱名义外径4.4、长15，顶部加1mm垫片。摇杆小板用后盖上的5.2mm支柱固定。
5. 背部转接PCB固定在下固定桥，公针对插主机背部排母；短线束从桥上的过孔通往按键板，再接摇杆小板。线束/连接器仅画机械占位。
6. 后盖用4颗M2×10固定；前壳中M2孔以1.6mm底孔建模，试装件需按材料攻牙或调整。其他名义螺钉：M2×6用于铜柱两端及摇杆板，M2×4用于转接板和十字键支点。模型螺钉头按最大直径4、厚1.6占位，螺纹未画。

主机模型沿用官方外廓，排母中心、排母凹陷深度、相机和部分细节仍是已有模型的估算。转接板固定坐标是当前名义值，不能把它当作已与实机对插验证。应先试配主机、连接器和压条，再固定最终转接板孔位。原机脚垫不当作螺孔，控制器不要求改动或钻原机外壳。

## 检查与重建

`mechanical-checks.json`记录实体有效性、固定件/主机干涉、板和外壳干涉、按钮行程、十字键8方向及摇杆运动包络。当前检查通过；杆帽还检查与保守模块外廓的相交。故意接触的螺纹、对插端子和开关触发位置不作为错误干涉。未做强度/疲劳仿真或实物配合验证。

`stl-checks.json`记录18个STL网格均封闭。网格封闭不等于打印无需支撑或装配必然成功。

```powershell
D:/Software/FreeCAD/bin/python.exe hardware/controller-v1/build_controller.py
# 随后在FreeCAD运行 render.FCMacro，补上显示颜色、文字并生成预览。
python hardware/controller-v1/draw_dimensions.py
```

FreeCAD文件中的尺寸表用于记录名义值，不是装配约束求解器。独立实体可以继续编辑；要系统改尺寸，应修改生成脚本/parameters.json后重建，并同步相关坐标及重新检查，不是仅改表格就会自动更新全部结构。重建会覆盖本目录的生成模型，修改原模型前请另存版本。
