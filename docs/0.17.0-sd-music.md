# 0.17.0 SD 文件与音乐

## 存储布局

默认只挂载已有受支持的 FAT 文件系统，失败不会自动格式化。挂载后创建 `/sdcard/Ouse/Music`、`Video`、`Pictures`、`Downloads`；不会搬动其他目录。应用安装仍使用内部 LittleFS，不支持安装到 SD 卡。

维护命令 `DBG_SDFORMAT` 仅允许对尚未挂载的卡执行 FAT32 格式化，必须传入匹配当前卡的 `名称:字节容量`，检查卡在线状态；已挂载时拒绝。此命令具有破坏性，只能在用户明确授权后使用。当前不支持 exFAT、NTFS 或 GPT 卷直接挂载。

`Ouse.files.get()` 返回只读缓存状态；`list(offset, limit)` 每次最多返回 8 首，曲库最多 64 首 WAV。`refresh()` 异步刷新，`download({url,path})` 返回原生任务 ID。文件访问需要 `capabilities.files`，下载还需要 `network`，播放还需要 `media`。路径仅接受上述四个目录的直接子文件，拒绝越界和隐藏文件。下载与串口上传均拒绝覆盖已存在文件，使用临时文件和成功后重命名；失败/取消清理本次临时文件。最大单文件 128 MiB，HTTP 下载最长 20 分钟。

磁盘操作在原生工作任务中进行；JS/UI 仅查询缓存。闲置时检查卡状态，拔卡后标记不可用；重新插入暂需重启，不支持自动重新挂载。不要在播放、下载或串口复制时拔卡。

## 音乐

界面参考微雪官方示例的唱片、曲目信息和圆形播放按钮，封面和布局独立实现。SD 曲库按文件名排序，支持分页、上一首/下一首、暂停/继续、停止、顺序/单曲循环，保留后台媒体会话和原有网络曲目入口。

当前原生解码仅支持 PCM16 WAV（单/双声道、8–48 kHz），不支持 MP3/AAC/FLAC，不支持拖动进度定位。网络下载不执行转码；音乐下载入口应使用真实 WAV 链接。

`tools/prepare-sd-music.py` 生成原有《致爱丽丝》30 秒示例以及莫扎特 K.545 的三个完整乐章（公有领域 MIDI 渲染录音），附来源许可。`tools/upload-sd-files.py --port COM5 --source <目录>` 复制 WAV 和许可文本；逐文件检查大小与 CRC32，不覆盖不同内容。

## 2026-10-18 实机记录

通过家用电脑 SSH 访问本机 CH343 COM5。TW000 卡容量 31,266,439,168 字节，原分区含 GPT 保护标记，原挂载返回 FR_NO_FILESYSTEM。取得用户明确授权后格式化为 FAT32；重启后识别 MBR 类型 0x0c，挂载与目录读取成功。

《致爱丽丝》示例 480,044 字节经串口复制并完整读回，CRC32 `abaad727`。其余三首传输于用户要求后停止，清理未完成的快板临时文件；最终曲库 1 首，卡状态 mounted/ready 均为真。后续改走网络传输，不再继续串口传歌。局域网 HTTP 下载尝试未成功，尚不能视为实机验证通过；新版音乐界面和 SD 播放控制也仍待实机验收。

串口工具默认使用 256 字节确认包，按可读字节数及时读取回复，保留序号重试与读回 CRC 校验。若掉电留下临时文件，可在确认后使用 `--discard-partial` 显式清理对应未完成目标的 `.part`，不会覆盖已完成的文件。
