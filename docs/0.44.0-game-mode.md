# Core 0.44.0 / Native API 47

应用可以在实际游戏和暂停界面启用防误触，在菜单禁用：

```js
Ouse.game.setEnabled(true);
Ouse.game.setEnabled(false);
```

仅前台应用可设置，不接受验证模式、后台、已关闭或故障实例的请求。
系统返回即将离开应用时，首次操作显示提示；2 秒内再次操作才允许离开。
全屏底部短上滑和导航栏 Home 同样受保护。应用内部返回、键盘和系统弹窗
优先处理；任务概览和应用主动调用 Ouse.home() 不受阻挡。
保护按应用实例保存，切换应用清除确认状态，关闭实例清除保护设置。

```js
let frameId = Ouse.timers.requestFrame(function drawNext() {
  updateAndDraw();
  frameId = Ouse.timers.requestFrame(drawNext);
});
Ouse.timers.clear(frameId);
```

requestFrame 为单次请求，使用既有每应用 8 个计时器槽位，返回句柄或 false。
回调须等待随后一次前台 UI pump 完成模型及 Canvas 交接，不设 20/30 FPS
定时器周期；后台不执行。回调仍遵守脚本时间和内存预算、输入优先级。
它不代表 SPI 传输完成或面板垂直同步；异步显示继续只保留最新待发送帧。
应用应按实际经过时间更新物理，不能将回调次数当作固定时间步长。

系统音量键的默认行为由每次 5 调整为每次 10，限制在 0..100。
浮层仅显示可直接拖动的滑条，不显示标题和数字；按键重复使用现有浮层，拖动时保持显示，
松手或最后一次按键后约 2 秒隐藏。调节仍经过原生音量服务，保留设置持久化、
应用前台按键拦截、电源键长按及唤醒触摸消费规则。
取消全屏退出手势时保留游戏原有视口尺寸，不因预览桌面而缩小画面。

0.44.1：音量浮层去掉外层面板背景，只保留可操作的滑条。
竖屏在右侧显示竖条，上滑增大音量；横屏在顶部显示横条，向右增大音量。

0.44.2：横屏音量条上移 24 dp；游戏退出提示简化为“请再次退出”。
冷启动时若全屏命令改变了视口，构建页面后重新发布尺寸及 display revision，
防止应用沿用进入全屏前的高度。补齐新游戏文字的常用字号位图；原字符像素、
字距、基线和 CJK 回退保持不变。两款游戏共用的 JS 调度器另设 25 FPS 上限，
慢帧不累积补发任务。

验证：完整 real LVGL core 回归，新增游戏防误触/超时/实例隔离/全屏 Home、
音量增减/边界/真实指针拖动/持续按住/横屏检查；real QuickJS 前台权限和
单次帧调度门槛；跳跳庄园三关、23 个旗子、音效及生命周期回归和 BPK 校验。
