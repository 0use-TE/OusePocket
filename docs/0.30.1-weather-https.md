# 0.30.1 天气与 HTTPS

原生 API 34，JS API 1。

## 根因

最初天气显示“定位失败：ESP_ERR_TIMEOUT”，自动模式每次刷新都先请求 GeoJS，导致定位接口失败时无法使用已有城市更新天气。修正应用后真机天气接口同样超时，进一步验证发现路由器、公网 Ping 和百度 HTTP 均正常，时间已同步、信号 -41 dBm，但百度 HTTPS、Open-Meteo、GeoJS 均超时。

本地 IDF 6.1 的 esp_tls.c 在 ESP_TLS_CONNECTING 中反复使用 tls->rset/wset；首次 select 的 50 ms 等待超时后集合被清空，下轮没有重新 FD_SET，后续一直等待空集合。延长整个请求超时并不能修复这个状态问题。

HTTP 层通过公开的 esp_tls_get_conn_state/get_conn_sockfd 检查 CONNECTING 状态，使用每次重建的独立 fd_set、50 ms select、SO_ERROR 和已有取消/总截止时间判断连接。确认 TCP 建连成功后，仅这一轮传入 non_block=false 跳过 SDK 已损坏的 select 集合，再继续原 TLS 状态机。SDK 在 INIT 已把实际套接字置为非阻塞，mbedTLS 后端不会因为这一轮配置切换而改变 socket 模式。后续握手仍使用正常非阻塞配置。SDK 源码未改，CA/主机名校验未关闭，不回退明文，也不无限重试。

该兼容处理覆盖 Ouse HTTP 服务及其调用者，不宣称修复 WebSocket/MQTT 内部使用的独立 SDK 传输路径。

恢复 HTTPS 后，GeoJS 又暴露出响应头限制：实际 CDN 响应约 19 项，Report-To 值超过原 255 字节，旧的 12 项/255 字节上限会拒绝完整 JSON 响应。现扩为 24 项、值最多 511 字节，累计响应字段/值仍限 4096 字节，正文仍 32 KiB。请求构造缓冲仍 5120 字节，每次追加均检查剩余空间，超限安全拒绝。原生 C 结构变更故 API 升为 34；这些工作数据沿用普通堆的 PSRAM 优先策略，不搬到线程栈。

## 应用

- 启动或普通刷新优先使用有效已存城市，自动模式不再每次重新定位。
- “自动定位”仍明确发起 GeoJS 请求，定位等待 8 秒；失败时已有城市继续查天气，无城市则提示搜索。普通天气请求仍 20 秒。
- 保留失败前的天气缓存和城市选择；切换到新坐标才清除不匹配的天气快照。
- 关闭取消在途请求，代际校验忽略迟到结果；晚到的存储恢复不覆盖用户已发起的操作。v2/v3 存储格式继续兼容。

## 测试

HTTP 主机夹具模拟连接进入 CONNECTING 后连续三次 select 超时并清空集合，必须恢复成功；同时测试等待到期、SO_ERROR 失败，不绕过取消/总时限。天气 Node 测试覆盖缓存刷新、定位回退、无位置搜索、友好超时、关闭和迟到存储隔离、坏坐标。应用包由原生校验器、QuickJS 与页面 schema 检查。

另覆盖 20 项响应头及 300 字节长值成功、超过 24 项响应拒绝、合计超长请求头安全拒绝。

诊断临时应用曾因超长 console.log 触发它自己的受限字符串错误（已删除测试包），不能把这条计为天气或内核故障。更新前的分层网络诊断记录见 `.tools/weather-probe2-serial.log`。

## 最终实机验证

COM10 仅写入 P4 0x10000 应用区，校验哈希成功；C6、NVS、分区表和用户存储未擦除。最终二进制 SHA-256 `b88a2e5c1dd64e265c1ec89d9b5c6cafb9760c3842f94b7aea79b7476b2d3cd9`。天气 BPK 已替换。

27 项统一回归与 UI ASAN 通过。最终网络探针：百度 HTTP 200 / 324 ms、百度 HTTPS 200 / 438 ms、Open-Meteo HTTPS 200 / 1,624 ms、GeoJS HTTPS 200 / 1,739 ms。普通天气刷新已从旧缓存 20°、湿度 96% 更新为 23°、湿度 80%，未依赖重新定位；这些是该次采样值，不是后续天气保证。

最终详细记录 `.tools/weather0301-final2.log`，串口分层记录 `.tools/weather0301-final-serial.log`；原始日志保留了修复 CDN 头限制前的试验，最终四项 200 以末尾一轮为准。

显式自动定位随后也取得经纬度并成功刷新天气，接口没有提供城市名时沿用“当前位置”，不伪造城市；IP 定位不等同于 GPS。测试包已卸载，最后保留天气在前台，errors=0、最近脚本异常为空、堆检查 ok=1，COM10 已释放。当前内部空闲 146,703 字节。
