# 音乐

独立 JSON＋JS BPK，需要 Ouse Core 0.13.0。安装包 `dist/bpk/music.bpk`，先更新固件再安装，旧固件无法接收大音源资源。

首页播放内置 30 秒《致爱丽丝》，无需网络。播放列表最多八首，含一首不可删除的内置音源；可加入 HTTP/HTTPS PCM16 WAV 地址。支持播放、暂停/继续、停止、上一首/下一首、单曲播放、顺序播放和单曲循环。列表和模式自动保存，修改列表前先停止播放。

回桌面后获许可的后台实例负责换曲，系统活动页可结束许可。暂停、停止、失败和列表结束会释放许可。关闭应用实例后当前原生曲目继续，停止后原生通知自动清理；关闭实例后不会自动换曲。通知可返回播放控制。

尚无 SD、MP3 或 seek；网络可用性取决于实际连接，已知 HTTPS 超时尚待定位。音源来源及许可见 AUDIO-LICENSE.md；片段为 8kHz 单声道 PCM16，受包大小限制，不代表高保真。
