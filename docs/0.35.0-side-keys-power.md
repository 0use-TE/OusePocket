# 0.35.0 侧键和电源菜单

Native API 39。板型为 ESP32-P4-WIFI6-Touch-LCD-3.5；BOOT 使用 P4 GPIO35，低有效；PWR_KEY 使用 GPIO49，经板上晶体管反相，高有效。两个引脚均配置成纯输入，不启用输出，不改变下载绑带及 AXP2101 的硬件长按断电设置。AXP2101 使用已有 BSP I2C 总线，地址 0x34。

20 ms UI 定时器读取 GPIO，30 ms 消抖。开机时已经按住的接触等待释放，不产生动作；息屏时第一次接触只唤醒，释放不触发音量或拍摄。默认短按 BOOT 加音量 5，PWR 减音量 5，范围 0..100；加音量解除静音，音量提示自动隐藏，设置沿用已有延迟持久化。应用切换中持续的按压不投递给新应用。

前台应用使用 `Ouse.keys.on("pwr", handler)` 或 `Ouse.keys.on("boot", handler)` 接管短按；传 null 释放。回调参数 `{key:"pwr",type:"click"}`。只有前台、就绪且未故障的实例可接管，后台声明不生效；系统对话框、输入法、最近应用及下拉面板优先。事件通过实例模型和页面代次交给脚本工作线程执行，UI 线程不调用 JS；关闭、切换页面或失去前台后不递送过期事件。每键最多一个待处理事件。

PWR 持续按住 2 秒显示系统电源菜单，不再产生短按；应用不能接管这个长按。菜单支持息屏、关机、重启，停止状态另有恢复运行。关机与重启需要确认。若有系统对话框，保留当前确认，不以长按覆盖它。PWR 约 6 秒的硬件强制关机仍由 PMIC 决定，持续按住可能绕过软件收尾。

软件关机复用原生协调器：阻止新工作、结束所有注册应用、等待原生任务/录音/媒体/存储/设置收尾及稳定窗口，然后在非 UI 线程将 AXP2101 0x10 的 bit0 置位。关闭遍历不再受 24 个最近应用容量限制。PMIC 不可用、I2C 写入失败或 USB 供电使板子仍运行时，不反复切电、不改成强制重启，保持停止状态并提示，可在电源菜单恢复运行。此操作不等于 USB 转串口及充电部分完全断电；USB 下保持关机效果需要硬件实测。息屏不等于深度睡眠。

相机把 PWR 短按绑定到与屏幕快门相同的函数，保留 SD、权限、忙状态检查；BOOT 保留系统音量加。相机 BPK 最低 API 39。

离线真实 LVGL 测试覆盖默认音量、启动按住抑制、前台接管、长按不同时拍照、确认/取消、唤醒接触消费；应用行为测试覆盖快门防重入与缺卡。硬件模拟测试执行生产 PMIC 读改写函数，验证地址/掩码/错误传播及超过 24 个应用的关闭遍历，不会实际切断设备电源。
