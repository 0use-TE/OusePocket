# Ouse 产品修复

基于官方快照 e937455b0db1a3e873b1da61d6d13652f3dcc7e2，GUI LVGL 0.8.5。

1. 调整组件依赖路径，主工程使用本地组件。
2. `BackendImpl::mount_screen`保留节点逻辑hidden状态。Runtime为Stack排序重新挂载兄弟屏幕时，已暂停应用不会被重新显示；正常可见屏幕卸载后仍能重新挂载。
3. `pocket_desktop.cpp` 按微雪旧 Phone 行为扩展截图缓存与原生最近任务：合成应用内容/Top标题栏，恢复原父对象与层级，横向居中截图卡片、上推关闭、点击恢复及全部关闭。卡片通过已有GUI事件通道异步通知Shell，并用面板代次过滤旧事件。
4. 新增左右边缘触摸拦截与跟手返回箭头，支持明暗主题；共享后端LVGL锁，析构先清理截图和原生对象。
5. 卡片垂直拖动不再限制为关闭阈值范围；拖动时临时移到全屏host，摆脱原slot/table裁剪，可上下跟手到屏幕边缘。松手上推达到阈值才关闭，关闭时不先跳回原位；下拉/短滑恢复原父级与位置。面板刷新或隐藏负责清理移出的卡片。

`tools/test-pocket-navigation.py`抽取真实挂载/卸载方法，在本机MSVC及后端替身上验证：参考版复现隐藏丢失，本地版通过。此测试覆盖可见性契约，不验证LVGL实际渲染、触摸硬件或像素布局。

`tools/test-phone-recents.py` 使用项目实际LVGL渲染器，验证截图像素、原场景恢复、缓存生命周期、圆角卡片、主题、边缘提示和指针交互。替换后端记录/事件接收端，不覆盖真实屏幕驱动和触摸帧率。
# 2026-10-15：最近任务提前关闭保护（待实机复测）

打开最近任务时让 LVGL 消耗仍按住的原始上滑，防止新卡片收到同一手势的合成 Pressed。卡片关闭不再由单次 Released 直接停止应用：先确认连续松手 80ms，再执行 180ms 滑出动画并发送关闭事件。期间接触恢复会取消待关闭，并保留原始拖动锚点。隐藏最近任务时删除待确认定时器和滑出对象，防止回调访问已释放卡片。

真实 LVGL 指针测试覆盖原始打开手势、单次断触/恢复、持续按住、滑出后关闭和待确认时隐藏。此保护不能仅凭现有设备日志确认触摸提前释放的硬件原因，需实机复测。
# 2026-10-15：拖动卡片的自动布局修正（待实机验收）

最近任务 JSON 的根容器为 flex column；上下拖动时卡片临时移到这个容器下，若不忽略自动布局，会被排到主体下方，导致按住时预览消失、松手恢复。原生主体和拖动卡片现在显式使用 `LV_OBJ_FLAG_IGNORE_LAYOUT`，保留手动坐标和全屏拖动范围。主机回归改用与固件一致的 flex 容器，不再以普通容器代替。
