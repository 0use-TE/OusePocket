# 0.31.0 商店与 SD 安装

内核 API 35、JS API 1。商店源可配置 HTTP 或 HTTPS，列表每页最多 12 条。包清单新增 versionCode（正整数）、versionName（1..31 UTF-8 字节）、minNativeApi（正整数）；旧包按版本序号 0、最低 API 1 处理。

## 接口

清单声明 `capabilities.packages: true`。发起安装必须处于前台，网络安装还需要 network，SD 安装需要 files 或 sdcard。每次安装均需系统确认，不提供静默授权。

```javascript
const task = Ouse.packages.install({url, id, size, sha256, versionCode});
const local = Ouse.packages.installFromSD("/Ouse/Downloads/example.bpk");
const progress = Ouse.packages.state();
const installed = Ouse.packages.list(0, 12);
Ouse.tasks.cancel(task);
```

安装返回任务 ID 或 false；接受不代表成功。state 含 taskId、busy、phase、appId、received、total、error。phase 为 queued、downloading、confirmation、installing、succeeded、failed 或 cancelled。全局仅一个安装任务，调用方须比对 taskId。list 返回 items、more；每项含 id、name、versionCode、versionName、system，limit 为 1..12。`Ouse.system.info().nativeApi` 返回内核 API 整数。

网络包最多 512 KiB，缓冲、请求元数据及解析资源使用 PSRAM。核对网络包实际长度、SHA256、包内 ID/versionCode；所有入口校验 ZIP、CRC、资源限制、最低 API、页面结构和 JS 编译。低内存、存储恢复中、SD 不可用时拒绝安装。SD 读取持有文件系统租约，读取完成释放，无自动格式化。

系统确认显示实际包名、ID、版本、来源及声明功能。确认阶段不阻塞 UI 或串口；取消、关闭发起应用或 120 秒不确认会终止。进入原子提交后不保证可取消。暂存包 flush/fsync 后原子替换：校验或写入失败保留旧包；若提交后激活失败，返回失败并可重启恢复已提交包。拒绝降级，同版本可重装，保留应用数据。应用仍装入内部 Flash。

HTTPS 证书验证服务器，ID 标识应用，SHA256 检查完整性；当前没有发布者签名，不能证明同 ID 来自同一作者。HTTP 允许用于可信局域网测试，但索引及哈希可能被篡改。协议、部署及备份见 [服务端 README](../cloud/store/README.md)。公网未部署，客户端暂用文字列表，尚未缓存远程图标。

## COM10 实测

仅烧录 P4 应用区 0x10000，未更新 C6、未擦除用户数据和 SD。

- 192.168.1.100:3000 的 Next.js HTTP 索引、下载、系统确认、安装 1.0 和打开通过。
- 资源管理器点击 SD BPK，确认 1.0 → 2.0，安装与打开通过。
- 错误 SHA：INVALID_CRC；错误 ID：INVALID_ARG；降级：INVALID_VERSION；不存在文件：NOT_FOUND。
- 排队取消、弹窗取消、关闭发起应用取消通过。安全卸载后安装返回 INVALID_STATE；重新挂载后原 2.0 应用仍可打开。

- 29 项主机回归、3 项服务端测试、Next.js 生产构建通过。本轮不代表长期运行、断电或物理拔卡测试。
