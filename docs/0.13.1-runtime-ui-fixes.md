# 0.13.1 运行时界面修复与实机确认

2026-10-17，根据用户四项实机反馈修复。工作区原有修改保持，未连接 GitHub，未改外部依赖、字体、分区、预算或音频驱动。用户要求直接烧录，本轮未额外备份。

## 原因与修复

- 音乐播放按钮消失：应用的 row 内三个 width=fill 控件被原生运行时分别设为父宽度的 100%，后两个落在右侧裁剪范围外。框架未定义主轴剩余空间分配，先前只检查 schema 和启动不足以发现几何问题。现 row 的 width=fill 使用零基础宽度和 flex grow 分配剩余空间；column 的 height=fill 同理，显式正 flexGrow 为权重，交叉轴 fill 保持。编辑器 CSS 同步。修复属固件通用布局，未以音乐按钮固定宽度规避。
- 浅色背景不一致：状态栏/底栏使用 desktop，应用内容默认 background，浅色两者不同而暗色相同。应用在前台时原生栏改用 background，桌面保持 desktop。计算器显式根背景原为 desktop，同时更新该应用为 background，避免它自行制造第二种背景。
- 计算器实时切换主题后部分按钮文字不见：子标签创建时设了本地文字颜色；父控件主题更新后，标签仍保留旧颜色。现在对子标签清理局部默认/状态文字色，由父控件实时继承语义/显式/状态文字色。AC 的错误色、括号/百分号的次要色、运算符显式白色继续保持。诊断树新增解析后的 fg 字段以核验。
- 最近应用顶部切割：之前虽允许子对象溢出，卡片条自身仍从 y=40 开始，绘制边界不能可靠覆盖顶部。现卡片条从屏幕 y=0 开始，将卡片正常位置从相对 y=10 改为 50，静止时屏幕位置不变；拖动范围进入顶部实际绘制区域。状态栏背景不透明度为 96/255，文字保留。滑出、回弹、上滑关闭的基准位置一起调整。
